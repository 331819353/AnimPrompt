# 封面与发布

构思开篇、封面、标题及发布文案时读取。封面沿用 [视觉与表演](visuals-and-performance.md) 的美术规范，按 [阶段衔接与续作](handoff-and-resume.md) 关联当前采用的剧本、角色与成片版本。

## 开篇、封面与发布文案

使用 Image Gen 完成封面创意小样、主视觉与局部修图；设计或排版工具完成标题、比例落版与导出。

Agent 先用文字确定各方案的核心看点和视觉关系，再调用 Image Gen 创作主视觉，查看实际结果后选择采用方案。标题、介绍和话题由 Agent 根据成片写作；中文字排版、三种比例落版、格式与尺寸检查可通过已验证字体及本地图片/排版工具实现，具体运行方式见 [制作执行与能力边界](production-execution.md)。

封面主视觉创作或重绘继续使用 Image Gen。文字、数值和准确尺寸使用工程工具控制，先预留布局再实际渲染；核对字体的中文覆盖、换行、字距、边距和对齐，不能把工具自动生成的文字当作已检查排版。发布文案保存到本地文件，实际上传或发布按用户本次明确要求执行。

动画按上/下或上/中/下交付时，每段分别制作三种比例封面及发布文案，保存到对应的分段交付目录，命名见 [分段成片交付](animation-and-delivery.md#阶段与最终交付)。各段沿用统一系列识别、角色与画风，封面主视觉、标题和介绍体现本段的真实冲突与看点，并标明上/中/下及播放顺序。上段和中段可保留指向后段的具体悬念，不能提前揭露后段关键反转或用下段结局冒充本段内容；各段的悬念提示须与采用剧本及实际动画一致。

1. 视频开篇可直接进入一个有吸引力的故事场景，也可使用约一至两秒的封面或标题画面，按剧情决定；封面画面与正文保持一致的角色和画风。
2. 封面是作品入口，必须吸睛、有创意、有美感，让观众第一眼看懂核心冲突、情绪或悬念，并产生观看兴趣。沿用正文所选形式的角色造型、轮廓、调色板和场景语言，独立设计构图、表演、光影与标题。
3. 每期提炼一个最有吸引力的核心看点，用一个鲜明的视觉关系呈现，例如人物之间的立场反差、关键道具与利益关系、出乎意料的处境或即将发生的选择。画面让人想知道“为什么会这样”或“接下来会怎样”，保留结局与关键反转。
4. 先用统一比例制作三种明显不同的创意构图小样，根据点击动机、第一眼识别、美感、故事契合度及适配能力选定一套，再扩展为三个成品比例。三种创意与三个比例分别统计，不要求为每种创意制作全套成品。小样可探索人物关系、关键道具或意外处境，在视觉创意、主体安排或叙事角度上有实质差异；简短记录选择理由。
5. 主视觉和标题形成清楚的主次，共同快速传达看点，辅助细节随后补充信息；具体阅读顺序服务于所选创意。主体轮廓、面部、手势和关键道具在缩略图中可辨，利用前后层次、人物朝向、视线和道具位置组织关系，控制信息数量并保留有目的的留白。
6. 美感通过协调且有辨识度的配色、明暗层次、形状节奏、空间安排及有取舍的细节体现。根据剧情选择冷暖、明暗或色相对比，让焦点自然突出；像素形式保持精细色块与阶梯轮廓，卡通形式保持线条、色块和表情清楚，整体色彩协调。
7. 角色表情与姿态具有感染力，能让人看懂惊讶、犹豫、得意、紧张或关系反差，程度符合人物与剧情。创意可以通过有依据的视觉比喻、道具比例或空间组织表达，角色身份、故事关系和关键道具仍须准确可辨。
8. 主标题建议六至十二个汉字，尽量两行以内，表达具体矛盾、悬念或观众关心的问题。标题与画面共同提供看点，文字清晰无错字，不遮挡面部和关键道具；字形、字距、对齐、颜色与背景共同设计，手机尺寸下可快速读懂。
9. 三种比例分别组织构图，重新安排主体、标题和辅助元素，保持同一套封面识别特征、核心看点和所选风格，避免简单拉伸或裁切导致表情、道具及标题丢失。交付尺寸为：
   - 4:3，1440×1080：cover_4x3.jpg。
   - 3:4，1080×1440：cover_3x4.jpg。
   - 16:9，1920×1080：cover_16x9.jpg。
10. 封面采用正文的视觉形式和输出规范。像素形式按 [像素形式](style-japanese-pixel.md) 固定密度与整数倍率安排逻辑画布：三倍放大时，4:3 使用 480×360、3:4 使用 360×480、16:9 使用 640×360，并以最近邻放大主视觉。卡通形式按 [卡通形式](style-satirical-cartoon.md) 在各比例的最终尺寸组织构图，保持清晰线条，不套用像素倍率。标题均使用核对后的文字层独立排版。
11. 每种比例同时检查完整尺寸、约 200 像素宽的缩略图及手机观看尺寸。快速扫视时应能认出主体、情绪、标题和核心看点；完整尺寸下检查配色、构图、所选形式的细节与整体美感。主体不清楚、标题难读、画面拥挤或悬念不足时，直接调整并复查。
12. 封面与标题呈现本段视频中真实存在的冲突与看点，观众进入视频后能获得对应内容；各段三个比例的封面在本段制作完成后对照实际成片复核，再跨段核对系列识别、顺序和悬念衔接。文件、源素材及检查记录统一按 [阶段与最终交付](animation-and-delivery.md#阶段与最终交付) 交付。
13. 根据每段实际成片分别制作发布文案：一个推荐标题、两个备选标题，约六十至一百二十字的标准介绍、约二十至四十字的精简介绍及三至五个相关话题。推荐发布标题与封面标题围绕本段核心看点，准确体现采用的二维有限动画形式，统一系列名并标明上/中/下。文案可留下具体悬念或判断入口，不泄露关键反转，也不把未交代的未来写成已发生事实。
