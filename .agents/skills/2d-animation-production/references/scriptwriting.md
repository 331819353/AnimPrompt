# 剧本创作

在根据主题创作或修订情景剧时读取。本文件规定故事与事实表达；将用户已有剧本制作成动画时，直接按 [阶段衔接与续作](handoff-and-resume.md) 接收，不强制改写成这里的生活类比形式。

根据用户提供的主题，创作一部“用生活故事讲懂复杂问题”的原创情景剧。

作品应具有生活质感、反向思考、合理反转和启发性。让没有相关专业知识的观众看得懂、愿意看，并能从故事中获得一种可以运用到其他问题上的判断方法。

## 写作与资料核验

Agent 明确本期机制、人物愿望与故事方向后，先完成包含场景、对白、动作、必要旁白和结局的完整主剧本，自查并请用户确认；再依据该版本编写上/下或上/中/下的完整分段剧本，自查并单独确认分段内容。方向大纲不能代替完整主剧本，主剧本确认也不能代替分段稿确认。

知识性表达使用当前可用的搜索、页面或文档读取工具核验关键来源，区分事实与推断；动态信息注明截止日期。资料暂不可访问时保留准确的待核实项，调整依赖该事实的表达，不能把搜索摘要或未读取链接当作已核实证据。

将两阶段成果写入作品目录，按 [阶段衔接与续作](handoff-and-resume.md) 分别保存版本与确认。只写剧本时不启动图片或配音；全流程在分段剧本确认后整理录音稿及人物/场景/关键道具清单，清单确认后才开始视觉素材生成。运行方式按 [制作执行与能力边界](production-execution.md) 处理。

### 先讨论选题与故事方向

方向尚未明确时，完成必要资料核验后向用户展示本期核心问题与范围、讲述价值及可能偏差，生活场景与人物关系，主人公愿望、主要冲突、关键因果与转折、拟定结尾及代表性对白。可预估总篇幅能否支持后续两段或三段，但正式分段稿在主剧本确认后编写。方案向审核内容的用户交代关键转折，不为保留观众悬念而隐藏。

请用户判断话题内容、故事方向及希望保留的重点；已有明确设定不重复询问。若选题尚未确定，先讨论题目和讲述角度；方向已经明确时直接完成主剧本，修改可自行修复的问题后请用户审阅剧情逻辑、人物行为、对白和结尾。获得主剧本确认后再进行下一阶段。

对自己无法确定且会改变故事的点，提出具体疑问，例如两种解释会导向不同结论、一个人物缺少可信的行动理由、类比可能误导或结尾偏离预期。说明影响与推荐处理，给用户可选择的方向。可查证的事实先自行核验；仍无法核实的关键依据明确标注，不要求用户凭喜好决定事实真假。常规细节直接处理，影响主线的未决事项在确定前不写成既定前提。

### 先确认主剧本再确认分段剧本

1. 主剧本是完整故事正文，包含人物动机、完整情节与因果、对白、关键动作、转折和结局，不是分段计划或梗概。先自查、交付实际文件并请用户确认整体内容；未确认前不直接交付分段定稿或投产图片。
2. 确认后按下方分段要求改编与丰富，交付各段完整正文、段界、约 3–5 分钟估时、段内看点、悬念与后续承接，说明相对主剧本的必要调整，再请用户确认分段稿。改变已确认主线、人物动机或结局时更新相应主剧本确认，不能借分段静默改写。
3. 保留已确认主剧本的快照和来源关系，后续录音稿、素材清单及动画统一依据已确认的分段版本，不平行维护两份互相矛盾的定稿。用户指定的已有剧本若已明确确认整体与分段，可直接复用对应范围；仍未审阅的清单与视觉成果继续按节点确认。

## 本期信息与默认值

从用户请求提取以下信息，已有明确偏好优先：

| 信息 | 默认与处理 |
| --- | --- |
| 主题 | 必要输入，结合本次请求确定 |
| 希望重点解释的问题 | 用户未指定时，从主题中选择能在本期讲清的核心问题 |
| 目标观众 | 普通大众 |
| 叙事结构 | 先确认完整主剧本，最终分段采用上/下或上/中/下；按冲突、变化与可支撑内容选两段或三段，用户指定时沿用，不为凑三段拖长剧情 |
| 时长或篇幅 | 每段目标约 3–5 分钟，包含对白、实际动作、反应与必要留白；写作时保存估算依据，制作时根据真实配音和表演核定，超出目标时调整内容与节奏 |
| 剧本风格 | 生活化、幽默、有讽刺意味，同时保留人情味 |
| 指定场景或人物 | 未指定时根据主题和故事安排 |
| 参考资料与事实截止日期 | 依据用户资料及必要核验确定，动态事件注明截止日期 |
| 其他要求 | 沿用用户明确的限制和偏好 |

用户未指定的信息先合理安排，作为方向方案的一部分展示，不必逐项追问；会改变主线或明显影响用户意图的假设须提出确认。
用户提供的观点和例子可以作为创作切入点，但需要检验其事实基础和解释范围。

## 按上下或上中下组织剧情

完整主剧本确认后，分段版本以“上、下”或“上、中、下”为主要叙事结构，正文可写“上：本段标题”“中：本段标题”“下：本段标题”，不使用章、节组织故事。每段内部用地点、时间和动作说明衔接场景，场景/镜头编号只用于制作记录。每段目标约 3–5 分钟，事件数量由完整剧情与节奏决定。

每段要有足以支撑约 3–5 分钟的实际剧情：人物目标遇到阻碍，行动带来变化，人物回应并作出新的选择，让观众获得本段的进展、情绪回报或理解上的发现。不能将一个短场景拉长为整段，也不能用重复解释、旁白总结、静态双人对白或无意义留白凑时长。写作估时分别考虑可朗读台词、实际动作和停顿，技术生成文本中的标签不计作台词；估算与真实配音/工程时长分别记录。

| 叙事段 | 本段需要形成的看点与推进 | 与后段的关系 |
| --- | --- | --- |
| 上 | 用具体愿望、异常处境或有代价的选择快速进入故事；人物行动引出第一轮冲突、变化与本段结果 | 在已发生的结果中留下尚待解决的问题、矛盾线索或新风险，观众能明确期待下一步 |
| 中（采用三段时） | 接续并回应上段悬念，让新行动扩大后果、改变关系或重新解释线索；形成新的选择和本段回报 | 推进上段伏笔，并用有因果的新代价、发现或决定引向下段，不能只复述上段或拖延答案 |
| 下 | 回应前段悬念、兑现关键伏笔，完成核心行动、代价、人物变化与主题发现 | 完成本期主线；若采用开放选择或循环反讽，仍交代必要结果，不承诺未计划的下一段 |

段内持续安排观众关心的变化：阻碍升级、信息揭示、关系改变、选择的代价、幽默或情感回报，按故事选择，不机械堆反转。每段开头建立本段要看的具体问题，中段让行动推进，尾部给出本段收获；上段和中段再留下指向下一段的悬念。后段开头尽快接续上一段的处境并推进其问题，必要前情通过简短、自然的信息衔接，不大段重复讲述。

伏笔来自人物行为、道具、未解决的条件、已有规则或有依据的矛盾。规划时记录“埋在哪里、观众会期待什么、后段怎样推进或兑现”，关键线索在前段实际出现；可有多条不同层次的线索，但只保留有后续作用的内容。段尾悬念必须与人物目标和本段结果有关，不用随机新秘密、突然中断完整动作或空喊“下段更精彩”代替铺垫，也不把本段所有回报扣到下一段。

分段依据已确认主剧本的剧情转折与因果边界，不能在一句台词、完整动作或应交代的结果中途机械截断。分段方案同时覆盖全部要求的段，分段稿交付各段完整对白、动作与结尾；只要求其中一段或局部修改时限定范围，并保存与前后段的衔接依据。

### 逐段改编与戏剧化展开

生成或按用户要求改编各段时，将话题、故事素材或简要情节展开为有戏剧性、可用于动画制作的完整情境。保留主题、事实依据、人物基本关系及用户指定的关键内容，在授权范围内补足动机、障碍、尝试、后果、转折和反应；虚构加工与现实事实区分，不能为了刺激而改写真实结果。已确认定稿在动画阶段需要实质改写时，回到剧本修订与审阅，先完成具体改稿再讨论取舍。

每段明确人物眼前想达成什么、受到什么阻碍、为什么不能轻易绕开、尝试后付出什么或改变了什么。冲突可来自不同目标、责任、有限资源、已有规则、信息差或有依据的误解；人物主动选择并承担后果，阻碍与转折有前文条件支持。按情境组织“目标与阻碍 → 尝试与后果 → 新发现或选择 → 本段结果”，不机械套用固定事件数量，也不靠角色突然降智、无理由争吵或新规则制造戏剧性。

丰富有叙事作用的生活细节和情绪变化：准备时的急切、尝试中的犹豫、事情失控后的反应、妥协时的代价、幽默或体谅的瞬间等，落实到具体行为与自然对白。新增人物、道具、场景或支线须能推动选择、揭示关系、形成回报或承接伏笔；删除无作用的添枝加叶，不用长篇解释和重复对白填满 3–5 分钟。

把抽象叙述转为可以演出的事件。例如“双方对交接是否完成有分歧”，可展开为一方按清单整理材料准备交接，另一方核对时指出未完成项，前者尝试补齐却发现已有条件发生变化，双方据此重新选择处理方式；未完成项和条件变化须由此前设定或线索支撑。这类改编应让观众看见行动、证据、受阻与回应，而非只听两个人争论概念；具体事件按本剧素材创作，不照搬例子。

每个关键情节交代地点与情境、参与人物和目标、动作前状态、必要行为与接触、动作后变化及人物反应。进出、拿取、递交、操作、查看、受阻、等待和转身等写成可理解的连续过程，人物内心变化通过表情、动作、选择或对白体现，关键因果不只写成“他意识到了”“事情变复杂了”。说明足够让制作阶段确定完整姿势、互动镜头和必要过渡图片；具体画布、帧数、机位及真实配音定时留到制作阶段核定。

交接时按上/中/下各段保存关键情节顺序、戏剧作用、动作与场景互动、人物/道具的前后状态、情绪转折及伏笔/兑现关系，可与正文动作说明和已有分段记录合并。每段都须能据此生成完整场景与动作序列，不能只交付几句梗概、概念争论或需要动画阶段重新编剧情的抽象说明。

## 明确本期要让观众看懂什么

主题较大时，选取一个能够在本期讲清的核心问题，并说明范围。

找出支撑这个问题的关键人物或组成部分、利益关系、运行规则、现实限制和因果过程。

保留足以影响理解和结论的必要背景，控制无关知识量。让观众能回答：
发生了什么？
为什么会这样？
谁作出了什么选择？
谁得到了什么，又由谁承担代价？

## 加入有依据的反向思考

从人们习以为常的解释、名称、承诺或评价出发，寻找其中被忽略的条件、成本、激励和后果。

可根据题材选择以下角度，不必全部使用：

- 某项安排声称解决什么问题，实际解决了多少？
- 谁获得直接好处，谁获得长期好处？
- 谁付出钱、时间、风险或失去选择权？
- 谁制定规则，谁解释规则，谁承担违反规则的后果？
- 提供服务的人，是否也控制着别人获得替代服务的机会？
- 参与是自愿的吗？拒绝、退出、更换或申诉的实际成本是多少？
- 如果相关人员都只是在合理追求自己的利益，为什么仍会产生糟糕结果？
- 被认为理所当然的关系，是否依赖某个很少被注意的前提？
- 当立场、权力位置或规则发生变化，同一行为还会得到同样的评价吗？
- 被普遍批评的安排，是否也存在容易被忽视的作用或必要条件？

选择最有解释力、最适合本期的角度深入展开。

不要预先规定所有组织都有恶意、所有善意都是骗局、所有常识都应被推翻。允许结论是“某种解释部分成立”“特定条件下才成立”或“问题出在具体机制”。

反向思考应增加理解：揭示新的关系、条件或机制。避免仅用一个更刺激的称呼替代分析。

## 将复杂关系转化为生活故事

选择观众熟悉、且与主题关键结构相似的生活场景，例如邻里相处、合伙经营、买卖交易、工作分工、学校活动、家庭开支、借用工具或排队办事。

重点对应：
人物身份与相互关系；
各自的目标和顾虑；
掌握的资源与受到的限制；
制定和执行规则的方式；
选择产生的结果与代价。

类比应当解释“事情如何运作”，不要只把国家、机构或专业概念替换成生活化名称。

不必把所有主题都写成村庄纠纷。科学、技术和系统类主题，可以通过日常操作或协作过程说明，不必赋予系统恶意或强行设置反派。

选定主要类比后保持稳定。若某个关键部分无法准确对应，应调整场景，或明确说明类比到此为止。

## 让新解读接受事实检验

涉及现实事件、历史、科学或其他知识性内容时，核对支撑主线的关键事实。需要最新信息时注明截止日期；无法核实的内容不要编造。

区分事实、当事方说法、分析推断和虚构加工。不要把推测的动机写成确定事实，也不要把虚构对白当成真实人物的原话。

检查生活比喻是否偷偷加入了现实中不存在的关系：
亲属称谓可能暗示服从或长幼秩序；
雇佣关系可能暗示管理权；
私人恩怨可能掩盖规则、组织或历史因素。

如果这些暗示会改变观众的判断，应在创作中修正。

认真考虑能够挑战本期解读的重要事实或其他解释。若它们会改变结论，应体现在故事或简短说明中，不必为了形式上的平衡平均分配篇幅。

讽刺可以尖锐，判断应与证据相称。

## 让人物和情节自身成立

主人公应有一个具体、日常、可以理解的愿望。由愿望遇到阻碍启动故事，不要让人物一出场就讨论主题或宣讲观点。

人物应有性格、顾虑、关系和表达习惯。可以自私、嘴硬、善良、犹豫或犯错，但行为要符合其处境和掌握的信息。

剧情形成清晰的因果链：
处境引出行动；
行动改变局面；
变化引出回应；
回应造成新的选择与后果。

每次重要转变都必须有足够的原因。交代清楚人物为什么加入、退出、妥协、反抗、误解或改变立场。

避免靠突然降智、刻意不沟通、巧合或临时规则推动故事。存在明显的简单解决办法时，应让人物尝试，或交代其行不通的原因。

场景可以跳转，关键因果不能省略。保持时间、信息、金额、规则和道具状态前后一致。

### 让对白发生在行动之中

每个分场交代人物正在做的具体事情、会使用或接触的道具、空间如何影响其行动，以及行动前后的变化。工作、交接、买卖、做饭或出行等活动通过人物的动作和对方反应演出，谈话随活动推进；关键冲突和转折要有可见行为及后果，不能把全部剧情写成两个人面对面解释主题。

按情境安排边做边说、动作造成的停顿、被环境打断、等待对方或无对白的回应。行为须服务于人物目标、关系或信息揭示，不为增加画面变化强塞无关动作；有明确情绪作用的安静对白可以保留。分场的动作说明应足够让动画阶段设计 [动作与场景交互](visuals-and-performance.md#动作与场景交互)，人物调度、具体景别与完整姿势由制作阶段落实。

## 把反向思考演出来

先让某种常见解释在具体场景中显得可以理解，再通过人物的行动与实际结果，让观众发现其中被忽略的部分。

例如，通过一笔账如何结算、一条规定如何执行、一次拒绝遭遇什么后果，逐渐显露真实的关系与代价。

不要让某个角色直接宣布“真相”，然后靠长篇发言完成揭露。

反转应来自前文已有的事实、规则、选择或伏笔。它可以改变观众对动机、受益者、成本、成败或某个细节的理解。

反转后必须表现实际后果，让人物作出符合其性格的反应或选择。

涉及真实事件时，优先设置理解上的反转，不得为了戏剧效果改写真实结果，或给尚未结束的事件编造确定结局。

## 语言有生活气，人物有人情味

用具体动作和自然对白表达：算账、借东西、留饭、推迟付款、改名单、递钥匙、履行承诺等。

幽默来自处境、关系和行为反差，少用网络热梗、连续金句和脱离身份的俏皮话。

温情通过人物之间的照顾、亏欠、体谅和选择积累。允许一个人在某件事上令人气愤，在另一件事上又让人理解或心疼。

保留普通人的尊严与复杂性。不要把人物写成只负责代表立场的符号，也不要把观众当成需要被训导的人。

### 对白保留自然说话的过程

按人物正在对谁说话、想争取什么、顾虑什么来写。真人开口往往先铺垫，再提出要求、解释缘由或补充细节；允许合理的重复、迟疑、自我修正、绕一下再说、被打断后接着说，以及长短句混用。这些表达能显出性格、关系和情绪，不以单位字数的信息密度评判台词好坏。

避免连续使用缺少主语或衔接的碎句，把时间、身份、任务和情绪压成摘要，或让每句话都承担金句、笑点和主题解释。礼貌试探、抱怨、亲近和焦急应有不同说法；有人惜字如金，有人爱解释，不能让全体角色共享一种整齐、利落的作者腔。删掉与情境无关的赘述，保留有表演作用的口语冗余；不要为了显得自然，机械地在每句塞入“嗯”“那个”、省略号或口头禅。

例如，原句“二十家店的灯箱稿都确认了。我今天能走了吗？六点半，闺女演一棵树。”把交代工作、请求离开和家庭缘由压得过紧。可改为：“二十家店的灯箱稿都确认好了。那我今天能走了吗？我闺女今天有演出，得扮演一棵树，六点半就开始了。”补足说话的衔接和“有演出”的背景，保留原有信息；实际用词仍随人物关系和当下语气调整，不把这一句套成所有角色的模板。

审读时逐段模拟两个人交谈，检查对方是否真的回应上一句、人物是否有必要解释这件事、哪些停顿来自思考或情绪、是否为了简洁删掉了听者需要的背景。发现摘要式对白先修改正文，不能只靠配音标签制造口语感。

## 结尾要启发判断

先交代关键行动已经造成的结果、代价及人物关系的必要变化。完整收束时交代最初目标的结果；开放结局时明确人物走到什么处境、面临什么选择，按下面的方法保留尚未决定的未来。

通过一个前后呼应的动作、物品、场面或简短对白，让观众重新理解开头。

从本期最有力的发现中，提炼一个能够迁移到其他问题上的判断方法，例如：
判断一项承诺，要看如何兑现；
判断一种安排，要看利益和成本如何分配；
判断一项权力，要看如何受到约束、纠错和追责；
判断一种选择，要看拒绝和退出是否真正可行。

根据故事选择合适的方法，不必照搬上述示例，更不要每期都使用相同结论。

启发应让观众知道“以后可以如何观察和判断”，避免只留下愤怒、恐惧、优越感或无力感。

不要使用“大家终于觉醒了”“这就是人性”“一切都是骗局”等包办式总结。也不要为了温暖而安排毫无依据的和解。

必要时可补充两三句简短片尾文字，点明观察方法与适用边界，不写成长篇说教。

### 结尾设计与观众参与

结尾方式依据本期主题和人物处境选择，与像素或卡通画风分别决定，不默认每个讽刺故事都需要恐怖、异化或悲剧。

- 完整收束：人物的核心目标获得结果，通过前后呼应的动作或细节留下启发。
- 开放选择：重要因果与代价已经显现，将人物置于有真实成本的下一次选择前。交代支持不同走向的线索，留出一个具体问题，例如是否接受、拒绝、继续或改变规则，不替观众宣布唯一答案。
- 循环反讽：当前事件已有结果，最后一幕以新的身份、话语或细节呼应开头，让观众看见同一机制仍可能继续。角色的自我解释可以与画面事实形成矛盾，作者保留必要距离，让观众判断这种结果意味着什么。

先确定本期希望观众重新审视的关系、条件或机制，再选择结尾载体。可使用一次未完成的选择、前后不同含义的同一道具、一句与事实相反的自我安慰或重复出现的规则；根据故事构思，不机械套用固定结尾。

吸引力应贯穿故事：开头建立具体愿望或反常处境；中段让选择产生逐步可见的后果；转折重新解释已有线索；结尾完成本期该交代的内容，并留下一个与主题相关的思考入口。停顿和尾声画面给观众时间消化，不靠连续抛问题、长篇解释或强制要求评论制造参与。

角色观点与作者判断分别处理。自我辩护、荒诞隐喻及反讽旁白可供观众分析，但不能替代现实事实、普遍因果或科学证据。关键解释仍须与来源和类比边界一致；真实事件的结果不因采用开放结局而改写。

剧本交接注明已交代的结果、保留的问题、有关伏笔与最后一幕的表演意图。动画和配音须保留这份意图，封面与文案保留关键反转，最终交付仍包含完整尾声。

## 交付前自行审读并修改

对已保存的完整稿逐场、逐段检查，再连贯审读全文，先找出可自行修复的问题并改稿，按 [阶段自查与放行](handoff-and-resume.md#阶段自查与放行) 保存检查对象、版本及问题复查结果。不能只回顾写作计划、抽看开头或凭“已经写完”判断剧本合格。

主剧本先检查完整故事、因果、人物、事实和对白；分段稿再增加分段节奏与逐段戏剧化检查。以下七项按当前稿件阶段核对，不能把尚未编写分段稿误报为分段已通过：

分段是否吸引且能够兑现：
结构为上/下或上/中/下，各段目标约 3–5 分钟，时长估算有实际台词与动作支撑；每段都有开场看点、推进和本段回报，上/中段的结尾悬念有前文线索，后段接续并兑现，最后一段完成主线。逐条核对伏笔与回收位置，不以章节标题、灌水或突然截断替代叙事设计。

每段是否有戏剧性且便于动画制作：
逐段核对目标、障碍、行动、后果和有依据的转折，新增细节是否有叙事作用；关键情节能否据正文直接设计人物表演、道具/空间互动、状态变化和过渡姿势，情绪是否有可见表达。缺少因果或只有抽象说明时补写具体情境与行为，不能将重新编剧情的工作推给动画阶段。

故事是否成立：
人物动机可信，事件有前因后果，转变有铺垫，核心问题得到交代。
逐场核对人物实际做了什么、使用了什么或受到怎样的空间影响、行为造成什么结果；连续分场若仅靠固定站位的对白解释推进，修改为符合人物目标的实际活动和反应。

类比是否准确：
关键关系对应，规则一致，没有额外带入错误的身份、权利、义务或动机。

反向解读是否有价值：
揭示了被忽略的机制，而非只做情绪化否定；结论有依据，也经得起重要反例的检验。

结尾是否有启发：
观众既能理解这一个故事，也能获得判断其他问题的方法；故事没有替观众包办所有结论。开放的问题有明确的处境、代价和线索，本期关键因果已交代，尾声能与前文呼应。

对白是否像人在交谈：
表达符合人物身份、关系与目的，有自然的衔接和回应；必要背景、铺垫与补充没有被压掉，长短与节奏有变化，没有连续金句、摘要碎句或机械口头禅。

能确定的问题直接修改成稿，修改后重新审读受影响分场及前后因果、对白回应、伏笔与结尾，检查是否引入新问题。已知可修复错误解决后再提交审阅，并简述检查覆盖与主要修改，无须展示逐项自检过程；需要用户取舍或仍影响主线的疑问，说明具体位置、影响与处理建议，随审阅稿明确提出。自行审读不能替代用户确认。

## 剧本交付与后续衔接

1. 剧名及一句话讲述范围。
2. 简短人物表与必要的场景说明，不提前泄露反转。
3. 主剧本阶段交付完整连续故事；主剧本确认后的分段阶段交付上/下或上/中/下完整正文，段内保留场景、对白、动作与必要旁白，各段附目标时长与估时依据，不使用章、节作为故事标题。
4. 简短的现实对应与类比边界，避免重复讲解主题。
5. 涉及可核实事实时，附少量关键来源；涉及动态事件时注明事实截止日期。

两阶段都交付完整正文供审阅，不用大纲或创作建议代替。分段稿另附简短交接说明：各段改编/丰富的重点、关键情节与动作/场景互动、看点与回报、段尾悬念、伏笔与后段兑现位置，制作说明不混入台词。主剧本请用户判断整体故事；分段稿再请用户判断段界、节奏、吸引力与承接，两次确认分别记录。

在作品目录保存主剧本确认快照与分段剧本，例如“剧名_主剧本.md”和沿用的“剧名.md”，提供文件链接并记录来源版本。按 [阶段衔接与续作](handoff-and-resume.md) 分别更新确认状态；只写剧本完成本次文字范围，从主题到成片在分段稿确认后整理待确认的人物/场景/关键道具清单及录音稿，清单确认后才生图。待审阅稿不能称为已确认定稿；无法保存文件时提供完整 Markdown 源文本并说明。

剧本区分对白、动作、必要旁白与现实对应说明。提供给动画阶段时，保留上/中/下与内部场景的对应关系、角色和场景稳定标识、有关故事规则、伏笔与兑现说明；来源、制作说明及叙事段标题只有明确需要朗读时才进入录音稿。用自检通过且经用户确认的成稿建立交接；用户已指定采用的剧本或明确授权跳过审阅时，记录依据并沿用，不重复要求确认。
