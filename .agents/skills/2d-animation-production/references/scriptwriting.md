# 剧本创作

在根据主题创作、改编或修订情景剧时读取。本文件规定故事与事实表达；仅将已有剧本制作成动画时按 [阶段衔接与续作](handoff-and-resume.md) 接收，不自动重写。用户要求改编时，按 [戏剧化悬疑与多时间线](dramatic-suspense-and-timelines.md) 形成完整修订稿，生活类比仅在适用时使用。

根据用户提供的主题，创作一部“用生活故事讲懂复杂问题”的原创情景剧。

作品应具有生活质感、戏剧冲突、悬疑吸引力、反向思考、合理反转和启发性。以多条有实际作用的时间线组织故事，加入自然人物对白与可演出的场景描写，完成悬疑线索的铺垫和回收。让没有相关专业知识的观众看得懂、愿意看，并能从故事中获得一种可以运用到其他问题上的判断方法。

## 写作与资料核验

Agent 明确本期机制、人物愿望与故事方向后，先完成包含场景、对白、动作、旁白和结局的完整主剧本，自查并请用户确认；再依据该版本编写上/下或上/中/下的完整分段剧本，自查并单独确认分段内容。旁白写出实际朗读正文及对应情境，不留到动画阶段临时补解释。方向大纲不能代替完整主剧本，主剧本确认也不能代替分段稿确认。

知识性表达使用当前可用的搜索、页面或文档读取工具核验关键来源，区分事实与推断；动态信息注明截止日期。资料暂不可访问时保留准确的待核实项，调整依赖该事实的表达，不能把搜索摘要或未读取链接当作已核实证据。

将两阶段成果写入作品目录，按 [阶段衔接与续作](handoff-and-resume.md) 分别保存版本与确认。只写剧本时不启动图片或配音；全流程在分段剧本确认后整理录音稿及人物/场景/关键道具清单，清单确认后才开始视觉素材生成。运行方式按 [制作执行与能力边界](production-execution.md) 处理。

### 先讨论选题与故事方向

方向未定时，核验必要资料后展示核心问题/事实边界、生活场景、人物愿望与冲突、关键转折、结尾及代表性对白，提出具体取舍。已有方向直接编写主剧本，不重复确认。

影响主线的疑问说明位置、影响和建议；可查事实先核验，未确定的前提不写成既定事实。主剧本审阅通过后再编分段稿。

### 先确认主剧本再确认分段剧本

1. 主剧本是完整故事正文，包含人物动机、完整情节与因果、对白、旁白、场景描写、关键动作、转折和结局，不是分段计划或梗概。按选定的多时间线呈现，附简短真实事件先后、各线作用及线索揭示/回收依据供审阅，不另写一份会漂移的顺叙正文。先自查、交付实际文件并请用户确认整体内容；未确认前不直接交付分段定稿或投产图片。
2. 确认后按下方分段要求改编与丰富，交付各段完整正文、段界、约 3–5 分钟估时、段内看点、悬念与后续承接，说明相对主剧本的必要调整，再请用户确认分段稿。改变已确认主线、人物动机或结局时更新相应主剧本确认，不能借分段静默改写。
3. 保留已确认主剧本的快照和来源关系，后续录音稿、素材清单及动画统一依据已确认的分段版本，不平行维护两份互相矛盾的定稿。用户指定的已有剧本若已明确确认整体与分段，可直接复用对应范围；仍未审阅的清单与视觉成果继续按节点确认。

用户提供的观点和例子可以作为创作切入点，但需要检验其事实基础和解释范围。

## 按上下或上中下组织剧情

完整主剧本确认后，分段版本以“上、下”或“上、中、下”为主要叙事结构，正文可写“上：本段标题”“中：本段标题”“下：本段标题”，不使用章、节组织故事。每段内部用地点、时间和动作说明衔接场景，场景/镜头编号只用于制作记录。每段目标约 3–5 分钟，事件数量由完整剧情与节奏决定。

每段要有足以支撑约 3–5 分钟的实际剧情：人物目标遇到阻碍，行动带来变化，人物回应并作出新的选择，让观众获得本段的进展、情绪回报或理解上的发现。不能将一个短场景拉长为整段，也不能用重复解释、旁白总结、静态双人对白或无意义留白凑时长。写作估时分别考虑可朗读台词、实际动作和停顿，技术生成文本中的标签不计作台词；估算与真实配音/工程时长分别记录。

| 叙事段 | 本段需要形成的看点与推进 | 与后段的关系 |
| --- | --- | --- |
| 上 | 用具体愿望、异常处境或有代价的选择快速进入故事；人物行动引出第一轮冲突、变化与本段结果 | 在已发生的结果中留下尚待解决的问题、矛盾线索或新风险，观众能明确期待下一步 |
| 中（采用三段时） | 接续并回应上段悬念，让新行动扩大后果、改变关系或重新解释线索；形成新的选择和本段回报 | 推进上段伏笔，并用有因果的新代价、发现或决定引向下段，不能只复述上段或拖延答案 |
| 下 | 回应前段悬念，汇合各时间线，兑现关键伏笔；讲明核心因果，重释前文细节，完成核心行动、代价、人物变化与主题发现 | 完成本期主线与人物情感收束；若采用开放选择或循环反讽，仍交代必要结果，不承诺未计划的下一段 |

段内持续安排观众关心的变化：阻碍升级、信息揭示、关系改变、选择的代价、幽默或情感回报，按故事选择，不机械堆反转。每段开头建立本段要看的具体问题，中段让行动推进，尾部给出本段收获；上段和中段再留下指向下一段的悬念。后段开头尽快接续上一段的处境并推进其问题，必要前情通过简短、自然的信息衔接，不大段重复讲述。

伏笔来自人物行为、道具、未解决的条件、已有规则或有依据的矛盾。按 [线索铺垫与回收](dramatic-suspense-and-timelines.md#线索的铺垫误导核验与回收) 记录真实含义、初次理解、谁能接触、铺垫/核验/回收位置及后果，关键线索在揭晓前实际可感知；可有多条不同层次的线索，但只保留有后续作用的内容。段尾悬念与人物目标及本段进展有关，允许有意停在明确待决的结果或选择上，记录恢复位置并在后段接续，不用随机新秘密或空喊“下段更精彩”替代铺垫，也不把本段所有回报扣到下一段。

分段依据已确认主剧本的剧情转折与揭示节拍，每段可交织多条时间线，不把每一条线机械分配为一段。不能截断一句台词或无计划地丢掉动作/结果；有意暂缓的动作或答案须有本段进展、明确未决状态及下一段恢复/兑现位置。分段方案同时覆盖全部要求的段，分段稿交付各段完整对白、动作、场景、旁白与段尾；只要求其中一段或局部修改时限定范围，并保存与前后段的衔接依据。

### 逐段改编与戏剧化展开

生成或按用户要求改编各段时，将话题、故事素材或简要情节展开为有戏剧性、可用于动画制作的完整情境。保留主题、事实依据、人物基本关系及用户指定的关键内容，在授权范围内补足动机、障碍、尝试、后果、转折和反应；虚构加工与现实事实区分，不能为了刺激而改写真实结果。已确认定稿在动画阶段需要实质改写时，回到剧本修订与审阅，先完成具体改稿再讨论取舍。

每段明确人物眼前想达成什么、受到什么阻碍、为什么不能轻易绕开、尝试后付出什么或改变了什么。冲突可来自不同目标、责任、有限资源、已有规则、信息差或有依据的误解；人物主动选择并承担后果，阻碍与转折有前文条件支持。按情境组织“目标与阻碍 → 尝试与后果 → 新发现或选择 → 本段结果”，不机械套用固定事件数量，也不靠角色突然降智、无理由争吵或新规则制造戏剧性。

丰富有叙事作用的生活细节和情绪变化：准备时的急切、尝试中的犹豫、事情失控后的反应、妥协时的代价、幽默或体谅的瞬间等，落实到具体行为与自然对白。新增人物、道具、场景或支线须能推动选择、揭示关系、形成回报或承接伏笔；删除无作用的添枝加叶，不用长篇解释和重复对白填满 3–5 分钟。

把抽象叙述转为可以演出的事件。例如“双方对交接是否完成有分歧”，可展开为一方按清单整理材料准备交接，另一方核对时指出未完成项，前者尝试补齐却发现已有条件发生变化，双方据此重新选择处理方式；未完成项和条件变化须由此前设定或线索支撑。这类改编应让观众看见行动、证据、受阻与回应，而非只听两个人争论概念；具体事件按本剧素材创作，不照搬例子。

每个关键情节交代地点与情境、参与人物和目标、动作前状态、必要行为与接触、动作后变化及人物反应。进出、拿取、递交、操作、查看、受阻、等待和转身等写成可理解的连续过程，人物内心变化通过表情、动作、选择或对白体现，关键因果不只写成“他意识到了”“事情变复杂了”。说明足够让制作阶段确定完整姿势、互动镜头和必要过渡图片；具体画布、帧数、机位及真实配音定时留到制作阶段核定。

交接时按上/中/下各段保存关键情节顺序、戏剧作用、动作与场景互动、人物/道具的前后状态、情绪转折及伏笔/兑现关系，可与正文动作说明和已有分段记录合并。每段都须能据此生成完整场景与动作序列，不能只交付几句梗概、概念争论或需要动画阶段重新编剧情的抽象说明。

多时间线的事件先后、人物知识、场景版本与揭示顺序按 [戏剧化悬疑与多时间线](dramatic-suspense-and-timelines.md) 管理。场景正文标明所属线、地点和日夜/相对时刻，写清环境如何影响人物行动和线索可见性；由一条线切到另一条线时，说明此次切换给观众增加什么信息，以及返回原线后怎样推动行动。悬疑布局在主剧本阶段成立，分段阶段落实节奏与跨段回收，不能只在标题里宣称多线或悬疑。

按 [交叉推进与结尾汇合](dramatic-suspense-and-timelines.md#交叉推进与结尾汇合) 将各线写成相互作用的完整故事：一条线的疑问在另一条线得到部分解释，再改变后续行动或观众判断，最终在最后一段完成因果、线索和情感汇合。结尾可用必要旁白或对白串清已经有证据支持的核心事实，并以人物行动和首尾呼应落地，让观众能够复原全貌、重新理解先前细节。

## 明确本期要让观众看懂什么

将宽泛主题限定为本期能讲清的核心问题，保留必要背景、规则与限制。观众应能理解发生了什么、为何如此、谁作出选择，以及收益和代价由谁承担。

## 加入有依据的反向思考

从常见解释、承诺或评价中找出被忽略的条件、成本、激励与后果，选择最有解释力的角度展开，例如实际效果、利益分配、规则制定权、退出成本或立场变化后的双重标准。

结论由事实和人物行动支持，允许部分成立或仅在特定条件下成立；不预设所有组织有恶意、所有善意是骗局，也不用更刺激的称呼代替解释。

## 将复杂关系转化为生活故事

选择观众熟悉且结构相似的生活情境，保留身份关系、目标、资源、限制、规则与选择后果的对应，不只替换机构或概念名称。

类比保持稳定，无法对应的关键部分调整场景或注明边界。科学、技术与系统类主题可通过操作或协作讲述，无需强行设置反派。

## 让新解读接受事实检验

核对支撑主线的现实、历史、科学等关键事实；动态信息注明截止日期，无法核实的内容标明缺口。区分事实、当事方说法、分析推断和虚构加工，虚构对白不冒充原话。

检查类比是否加入不存在的权利、义务、身份或动机；会改变判断的重要反例和其他解释须纳入故事或简短说明。讽刺程度与证据相称。

## 让人物和情节自身成立

主人公应有一个具体、日常、可以理解的愿望。由愿望遇到阻碍启动故事，不要让人物一出场就讨论主题或宣讲观点。

人物应有性格、顾虑、关系和表达习惯。可以自私、嘴硬、善良、犹豫或犯错，但行为要符合其处境和掌握的信息。

剧情形成清晰的因果链：
处境引出行动；
行动改变局面；
变化引出回应；
回应造成新的选择与后果。

每次重要转变都必须有足够的原因。交代清楚人物为什么加入、退出、妥协、反抗、误解或改变立场。

避免靠突然降智、刻意不沟通、巧合或临时规则推动故事。存在明显的简单解决办法时，应让人物尝试，或交代其行不通的原因。

场景可以跳转，关键因果不能省略。保持时间、信息、金额、规则和道具状态前后一致。

关键事件按 [叙事连续性与镜头衔接](story-continuity.md) 推演目标/决定、启动执行、必要过程或合理省略、结果/交接、回应及下一步。将这些依据落实到正文动作与已有交接记录，区分未执行、执行中、失败、完成及待核验；核对人物通过什么得知新信息，不让人物先回应尚未发生的结果。主剧本先保证事件成立，分段稿再核对场景和段界，不能把因果缺步留给生图补救。

### 让对白发生在行动之中

每个分场交代人物正在做的具体事情、会使用或接触的道具、空间如何影响其行动，以及行动前后的变化。工作、交接、买卖、做饭或出行等活动通过人物的动作和对方反应演出，谈话随活动推进；关键冲突和转折要有可见行为及后果，不能把全部剧情写成两个人面对面解释主题。

按情境安排边做边说、动作造成的停顿、被环境打断、等待对方或无对白的回应。行为须服务于人物目标、关系或信息揭示，不为增加画面变化强塞无关动作；有明确情绪作用的安静对白可以保留。分场的动作说明应足够让动画阶段设计 [动作与场景交互](visuals-and-performance.md#动作与场景交互)，人物调度、具体景别与完整姿势由制作阶段落实。

## 把反向思考演出来

先让某种常见解释在具体场景中显得可以理解，再通过人物的行动与实际结果，让观众发现其中被忽略的部分。

例如，通过一笔账如何结算、一条规定如何执行、一次拒绝遭遇什么后果，逐渐显露真实的关系与代价。

不要让某个角色直接宣布“真相”，然后靠长篇发言完成揭露。

反转应来自前文已有的事实、规则、选择或伏笔。它可以改变观众对动机、受益者、成本、成败或某个细节的理解。

反转后必须表现实际后果，让人物作出符合其性格的反应或选择。

涉及真实事件时，优先设置理解上的反转，不得为了戏剧效果改写真实结果，或给尚未结束的事件编造确定结局。

## 语言有生活气，人物有人情味

用具体动作和自然对白表达：算账、借东西、留饭、推迟付款、改名单、递钥匙、履行承诺等。

幽默来自处境、关系和行为反差，少用网络热梗、连续金句和脱离身份的俏皮话。

温情通过人物之间的照顾、亏欠、体谅和选择积累。允许一个人在某件事上令人气愤，在另一件事上又让人理解或心疼。

保留普通人的尊严与复杂性。不要把人物写成只负责代表立场的符号，也不要把观众当成需要被训导的人。

### 对白保留自然说话的过程

按人物正在对谁说话、想争取什么、顾虑什么来写。真人开口往往先铺垫，再提出要求、解释缘由或补充细节；允许合理的重复、迟疑、自我修正、绕一下再说、被打断后接着说，以及长短句混用。这些表达能显出性格、关系和情绪，不以单位字数的信息密度评判台词好坏。

避免连续使用缺少主语或衔接的碎句，把时间、身份、任务和情绪压成摘要，或让每句话都承担金句、笑点和主题解释。礼貌试探、抱怨、亲近和焦急应有不同说法；有人惜字如金，有人爱解释，不能让全体角色共享一种整齐、利落的作者腔。删掉与情境无关的赘述，保留有表演作用的口语冗余；不要为了显得自然，机械地在每句塞入“嗯”“那个”、省略号或口头禅。

例如，原句“二十家店的灯箱稿都确认了。我今天能走了吗？六点半，闺女演一棵树。”把交代工作、请求离开和家庭缘由压得过紧。可改为：“二十家店的灯箱稿都确认好了。那我今天能走了吗？我闺女今天有演出，得扮演一棵树，六点半就开始了。”补足说话的衔接和“有演出”的背景，保留原有信息；实际用词仍随人物关系和当下语气调整，不把这一句套成所有角色的模板。

审读时逐段模拟两个人交谈，检查对方是否真的回应上一句、人物是否有必要解释这件事、哪些停顿来自思考或情绪、是否为了简洁删掉了听者需要的背景。发现摘要式对白先修改正文，不能只靠配音标签制造口语感。

### 旁白参与故事说明与剧情推动

主剧本和上/下或上/中/下各段都安排有明确作用的旁白，与人物行动和对白共同讲故事。先确定叙述者的视角、语气及知道哪些事实；默认第三人称画外叙述，需要第一人称回忆或其他形式时明确其身份与知识边界。旁白的推断、反讽或角色自我解释须与已成立的事实区分，按揭示计划控制信息；可先展示结果再追问原因，不超出当前设计泄露谜底，也不把主观说法伪装为客观事实。

| 用途 | 怎样帮助故事推进 | 对应画面与检查 |
| --- | --- | --- |
| 建立背景和眼前目标 | 用自然语言交代理解行动所需的处境、关系、限制或旧事，让观众知道人物为什么急、为什么犹豫 | 配当前场景、人物活动或有依据的回忆；新增事实与采用剧情一致，不只罗列人物履历 |
| 衔接时间、地点和非关键过程 | 压缩无事发生的路程或等待，说明时间经过和任务如何接续，帮助观众进入下一场 | 配离开与到达等两端线索，人物携物及任务状态承接；关键交接和转折仍呈现 |
| 提炼因果和新的处境 | 在行动与结果之间补足画面难以独立表达的条件、代价、误判或关系变化，使观众理解下一步为何发生 | 依托已经建立的规则及实际事件，区分送到、核对、接受等进度；不凭一句话宣布尚未发生的成功 |
| 引出下一步或段尾悬念 | 从本段结果中指出尚未解决的具体问题、风险或选择，引导观众继续看人物怎样应对 | 与实际结果及后段兑现一致，不空喊预告，也不替人物提前作决定 |

每处旁白在正文标明“旁白：实际朗读内容”，动作、情境、用途及对应事件单独说明，进入分镜后关联镜头。采用“具体处境或变化 → 观众需要知道的信息 → 人物接下来的行动或问题”组织内容，不设固定条数、时长占比或逐镜解说频率；短句和长句自然搭配，避免连续金句、说教或照读画面上显而易见的动作。旁白可补充画面以外的必要背景，信息须有剧情或事实依据；观众听到不等于场内人物听到，人物回应仍须有自己的信息来源。

例如交接故事可在开场配小林整理稿件说：“小林原以为，把修改稿送到前台，这件事就算办完了。”省略无事发生的路程后，画面呈现到达、递交、接稳与核对；发现缺签时保留对方的提示和小林的反应。随后可配一句“稿子是送到了，可这交接还没算结束。”承接他准备补签的选择。旁白分别交代预期与新的处境，不替代交接过程；示例只演示写法，是否缺签及其他情节仍以采用剧本为准。

按叙事呈现顺序安排旁白进入和结束，与所指故事时刻及人物知识核对；切到过去、并行事件或回到当下时，用足够线索帮助观众定位，给关键对白、感知、反应和无声表演留出空间。用自然的说话方式说明故事，不为每个动作补一句旁白；旁白没有新增说明、承接或推进作用时改写或删除，整段仍保留确实有作用的叙述。估时把旁白与对白纳入朗读量，区分它们和动作的重叠与独占时段，不能将并行声画简单相加凑成 3–5 分钟。

用户指定的已有剧本需要补充旁白时，先形成带具体位置和正文的修订稿，在既有剧本确认节点审阅；录音与剪辑采用确认后的文本。只补说明或衔接时不顺带改变主线、动机和结局，实质变更按原确认规则处理。

## 结尾要启发判断

交代核心行动的结果、代价和必要关系变化，以已有动作、物品或对白呼应开头。启发来自故事中的判断依据，例如承诺怎样兑现、成本如何分配、权力怎样纠错或退出是否可行。

开放选择交代当前处境与代价，保留有依据的未来；避免包办式总结和无铺垫和解。必要时用两三句片尾文字说明适用边界。

### 结尾设计与观众参与

结尾方式依据本期主题和人物处境选择，与水彩或卡通画风分别决定，不默认每个讽刺故事都需要恐怖、异化或悲剧。

- 完整收束：人物的核心目标获得结果，通过前后呼应的动作或细节留下启发。
- 开放选择：重要因果与代价已经显现，将人物置于有真实成本的下一次选择前。交代支持不同走向的线索，留出一个具体问题，例如是否接受、拒绝、继续或改变规则，不替观众宣布唯一答案。
- 循环反讽：当前事件已有结果，最后一幕以新的身份、话语或细节呼应开头，让观众看见同一机制仍可能继续。角色的自我解释可以与画面事实形成矛盾，作者保留必要距离，让观众判断这种结果意味着什么。

先确定本期希望观众重新审视的关系、条件或机制，再选择结尾载体。可使用一次未完成的选择、前后不同含义的同一道具、一句与事实相反的自我安慰或重复出现的规则；根据故事构思，不机械套用固定结尾。

吸引力应贯穿故事：开头建立具体愿望或反常处境；中段让选择产生逐步可见的后果；转折重新解释已有线索；结尾完成本期该交代的内容，并留下一个与主题相关的思考入口。停顿和尾声画面给观众时间消化，不靠连续抛问题、长篇解释或强制要求评论制造参与。

角色观点与作者判断分别处理。自我辩护、荒诞隐喻及反讽旁白可供观众分析，但不能替代现实事实、普遍因果或科学证据。关键解释仍须与来源和类比边界一致；真实事件的结果不因采用开放结局而改写。

剧本交接注明已交代的结果、保留的问题、有关伏笔与最后一幕的表演意图。动画和配音须保留这份意图，封面与文案保留关键反转，最终交付仍包含完整尾声。

## 交付前自行审读并修改

审读已保存的完整正文，主剧本检查完整故事，分段稿再核对各段与边界；先修可判断问题，再提交用户审阅。按 [阶段自查](handoff-and-resume.md#阶段自查与放行) 保存版本、位置、问题及复查结果。

| 检查项 | 要求 |
| --- | --- |
| 分段 | 上/下或上/中/下，各段约 3–5 分钟有实际声画支撑，本段看点/回报、段尾悬念与后段接续/兑现完整 |
| 戏剧性 | 目标、阻碍、行动、后果和转折有依据，新增细节有作用，场景与关键行为可直接设计表演 |
| 因果与交互 | 按 [事件链](story-continuity.md) 核对决定、执行、省略两端、交接/结果、信息来源、回应和下一步；不以固定站位对白承载全部行动 |
| 类比与事实 | 对应关系和规则准确，必要来源可核验，无虚构的身份、权利、义务或动机 |
| 反向解读 | 揭示条件或机制，结论有依据，经得起重要反例 |
| 结尾 | 核心结果交代，伏笔和各线汇合，人物回应与情感落点成立，开放问题有处境、代价和线索 |
| 对白 | 符合身份与说话目的，有铺垫、回应、补充和长短变化，无连续摘要碎句或机械口头禅 |
| 旁白 | 各段有实际说明/推进作用，正文与情境对应；视角/知识和揭示顺序正确，不抢反应、泄底或凭空宣布完成 |
| 多线悬疑 | 按 [多线自查](dramatic-suspense-and-timelines.md#写作及制作自查) 分别复原真实因果与观众信息；交叉有作用，线索可感知、有核验及回收，结尾能讲清先后、动机和证据关系 |

修改后复查相关分场、对白/旁白、知识状态、伏笔、结尾及下游依赖。未决创作取舍附具体影响与建议，自查不能代替用户确认。

## 剧本交付与后续衔接

1. 剧名及一句话讲述范围。
2. 简短人物表与必要的场景说明，不提前泄露反转。
3. 主剧本阶段交付完整连续故事；主剧本确认后的分段阶段交付上/下或上/中/下完整正文，段内保留场景、对白、动作与实际旁白正文、叙述视角及说明/推进意图，各段附目标时长与估时依据，不使用章、节作为故事标题。
4. 简短的现实对应与类比边界，避免重复讲解主题。
5. 涉及可核实事实时，附少量关键来源；涉及动态事件时注明事实截止日期。

两阶段都交付完整正文供审阅，不用大纲或创作建议代替。主剧本附真实事件先后、多条时间线作用、人物/观众信息范围及线索揭示与回收计划；分段稿细化各段的改编、场景/行动、历史状态、省略依据、回应/下一步、看点与回报、段尾悬念及跨段兑现。制作说明不混入台词，记录与已有连续性/分场表合并，不重复维护故事正文。用户审稿能看到真实因果与谜底，面向观众的简介保留悬念。主剧本请用户判断整体故事；分段稿再请用户判断段界、节奏、吸引力与承接，两次确认分别记录。

在作品目录保存主剧本确认快照与分段剧本，例如“剧名_主剧本.md”和沿用的“剧名.md”，提供文件链接并记录来源版本。按 [阶段衔接与续作](handoff-and-resume.md) 分别更新确认状态；只写剧本完成本次文字范围，从主题到成片在分段稿确认后整理待确认的人物/场景/关键道具清单及录音稿，清单确认后才生图。待审阅稿不能称为已确认定稿；无法保存文件时提供完整 Markdown 源文本并说明。

剧本区分对白、动作、旁白正文与现实对应说明。提供给动画阶段时，保留上/中/下与内部场景的对应关系、角色和场景稳定标识、旁白叙述身份与用途、有关故事规则、伏笔与兑现说明；来源、制作说明及叙事段标题只有明确需要朗读时才进入录音稿。用自检通过且经用户确认的成稿建立交接；用户已指定采用的剧本或明确授权跳过审阅时，记录依据并沿用，不重复要求确认。
