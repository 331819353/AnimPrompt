# 视觉与表演

在镜头构思、图片制作、场景连续性、信息可视化和动作设计时读取。本文件规定故事画面、角色、道具、特效与封面共同使用的美术和表演语言。

采用作品选中的 [常规像素](style-japanese-pixel.md) 或 [讽刺手绘卡通](style-satirical-cartoon.md) 形式。两者共用完整动作图片、场景连续性和有限动画组织：以可复用的完整图片序列、角色移动、道具变化、环境特效和镜头剪辑演出剧情，嘴形、表情和手势包含在完整姿势图片中。每个变化单元至少六张有效不同图片，替换速度依据实际表演和声音测试调整，图片数量与播放速度分别核对。

每个场景先理解叙事作用、人物意图和情境条件，再自主选择表演与信息表达。采用剧本和输出范围见 [主入口](../SKILL.md)，素材的版本、交接和续作见 [阶段衔接与续作](handoff-and-resume.md)。

Agent 按 [即梦优先与 Image Gen 备用](canvas-and-image-routing.md) 制作美术内容并统一整理到即梦画布，使用图片读取与本地程序进行技术整理、场景合成和检查视图。实际图片创作、可重复工程和检查依据按 [制作执行与能力边界](production-execution.md) 分工，先用完整基准和代表性动作小组验证可用性，再展开全片素材。

内容：镜头与信息表达、动作与场景交互；视线、阅读面与道具朝向；场景素材与分层合成；所选美术与角色一致性；动作与表演、多帧切换及肢体与头身动作检查。仅用到其中一部分时阅读相应章节。

## 镜头与信息表达

1. 阅读剧本与各段改编/丰富说明，理解主题、人物关系、目标、冲突、关键情节、情绪转折、动作与前后状态，保留已确认的核心剧情、对白含义及结局。若关键行为、因果或状态变化仍只有抽象说明，按 [逐段改编与戏剧化展开](scriptwriting.md#逐段改编与戏剧化展开) 补齐剧本交接，实质改写回到剧本修订；常规机位、调度与过渡姿势可在制作阶段自主细化。
2. 将剧本拆成“场景→镜头→动作段→姿势帧”。判断每段需要观众理解或感受到什么，再选择建立环境、对白、反应、动作、细节揭示或转场等镜头组织方式。
3. 表演结合说话内容、潜台词、对象和反应设计。一段对白可以延续同一构图，也可以跨越多个动作；镜头切换由叙事需要决定，不按台词数量或说话人机械分配。
4. 景别、机位与构图服务于注意力和情绪，空间关系与视线方向清楚。改变视角时，角色比例、环境结构和对象身份仍依据同一设定。
5. 每个场景都推演人物行为与环境变化的依据。根据动作性质选择关键步骤、反应和状态，具体方法按 [动作与表演](visuals-and-performance.md#动作与表演) 执行，不为了复用动作而删改剧情。
6. 总时长依据定稿配音、动作和情绪停顿确定。复杂信息保留理解与反应时间，具体定时按 [配音与音频](voice-and-audio.md) 核定。
7. 信息可视化先识别理解难点，再选择最合适的表达方式：数量或进度可用计数器、刻度或排列；差异可用并置对照；关系可用构图与视线；细节可用局部特写或放大。仅在有助于理解时使用，形式与时代、场景及选中的美术语言协调。
8. 创意体现在信息如何融入剧情和表演。安排出现、变化与收束的时机，控制同时展示的信息量，重要内容留足阅读时间；数值、单位和比较口径准确，目标、假设与已经发生的结果区分清楚。
9. 细节视窗与特写依据原对象制作，按所选形式的尺寸与排版规范呈现对应的形状、文字和含义，不改变事实。与主画面保持明确关系，手机尺寸下可读，不遮挡主要表演或字幕。
10. 根据实际使用的信息设计保存内容依据、形式、关联镜头或变化时刻及素材来源。动态数据显示引用 [动作与表演](visuals-and-performance.md#动作与表演) 的状态记录，其他信息标明来源；场景内道具与说明性图层分别组织。

### 动作与场景交互

1. 每场先确定人物当前正在进行的具体活动、想完成的事情、会使用或受到影响的物件与空间，以及行动产生的结果。把场景作为行动发生的条件：人物在桌边整理材料、从柜中取物、进出门口、受拥挤位置阻挡、将物品递给别人等，按本剧情选择；背景中的环境与道具须有实际用途，不能长期仅作人物对白的装饰。
2. 将关键活动组织为观众能看懂的行动、接触、物件/空间状态变化和人物回应。拿取要有接触与归属变化，递交要有接收，开门要有门的状态和通行变化，坐下要有椅子与身体支撑；相关结果在后续镜头延续。剧情需要发生的事应实际演出，不能只让人物站着口头宣告已经发生。
3. 对话结合人物正在做的事、对方的反应和环境变化安排，允许边做边说、动作打断一句话、停下来等待对方或默默完成一个动作。例如工作交接场景可安排核对桌上的稿件、递材料、收拾东西准备离开，话语与行动前后有因果；动作选择仍须符合采用剧本，不因丰富画面擅自增加改变主线的新事件。
4. 根据活动和注意力组织人物位置、朝向、进出、坐站、距离及遮挡，镜头采用适合当前叙事的景别与机位。关键接触、道具变化和反应能清楚看见，人物比例与环境尺度自然；避免连续使用同一远景、固定左右站位和始终很小的全身角色，形成视觉小说或交互游戏式对白布局。近景、特写、反应镜头和空间变化按叙事需要使用，不机械按说话人切镜头。
5. 镜头推拉、背景特效、人物上下弹跳、重复点头摆手或嘴形开合，本身不算动作与场景交互。安静对话、静止镜头和停顿可以承担明确的情绪作用，但整场与整片不能依靠同一站位的轮流说话承载所有行动和转折；也不为凑交互次数随意加走动、拿放或无关动作，不设机械的换镜头频率。
6. 按互动需要生成完整角色及随动作关联的道具，或使用统一机位的完整镜头动作图片表现复杂接触。桌椅、门柜和前景的遮挡、接触与状态采用对应素材/场景版本，固定结构保持连续；不能因便于叠加两个角色而删掉接触步骤、把人放在家具前悬空表演或省略动作结果。相关图片仍遵守整图换帧、肢体与道具朝向检查。
7. 在镜头/动作表中记录场景活动、互动对象、关键接触、动作前后状态、人物调度和对应对白/反应，再落实素材与时间轴。代表性样片必须包含一段真实的角色—道具或角色—空间互动及其结果，不能只展示站立对话、嘴形和镜头运动就宣称表现基准通过。
8. 自查连贯查看整场、整段及全片，判断观众是否能描述人物实际做了什么、场景如何影响行为、行动后发生了什么变化；检查是否连续退化成固定背景前两个小人轮流说话。互动不足时修改动作组织、调度和镜头，补齐必要的完整姿势/镜头图片与状态变化，复查节奏、接触和连续性；不能只增加无目的的动效交差。

### 视线、阅读面与道具朝向

1. 先确定人物正在看哪个面，再确定人物、道具和镜头的位置。屏幕、书的内页、纸条或票据的文字面朝向阅读者，视线落在实际可读的面上；握持方向、手指接触、物件厚度、透视与遮挡支持同一空间关系。这项检查同时适用于像素和卡通形式。
2. 人物面朝镜头或镜头位于人物前方时，人物看手机，镜头应看到手机背壳及合理的后置摄像头；人物看展开的书，镜头应看到外侧封皮和书脊；人物看单面纸条或票据，镜头应看到纸背。不要把可读面转向观众，却让人物继续盯着道具背面，也不要在背壳上画屏幕、在纸背上重复正面的文字。
3. 观众需要知道内容时，另安排人物视角、肩后镜头或符合原道具朝向的内容特写；也可用明确属于说明层的信息视窗。人物主动把道具展示给别人或镜头时，表现翻转、递出或改变观看位置的动作，并保留前后连续性；不能用阅读姿势冒充展示姿势。内容可读性不能通过破坏原镜头的物理关系获得。
4. 每个阅读或展示动作在镜头/动作表中按需记录阅读者、视线目标、可读面朝向、机位、镜头可见面及握持状态。拿起、转动、翻页、递交、放下或切换机位后重新核对；同一阅读动作的嘴形、表情和手势换帧不能无故让道具正反面跳变。
5. 生成提示写明具体可见关系，不只写“人物看手机”或“人物读纸条”。例如：“镜头位于人物正前方；人物低头看手中的手机，屏幕朝人物，观众只看见手机背壳，手指自然握住边缘，视线朝向被遮住的屏幕。”书、纸条和票据同样明确内页/文字面朝人物、镜头看见外侧或纸背；动作变化继续输出包含人物和道具的完整姿势或完整镜头图片。
6. 实际查看生成图片、同组换帧及合成预览，逐项核对视线、可读面、握持与机位，不能仅凭提示词已写入就登记通过。发现反向阅读、道具正反面混淆或无依据翻面时，用所选生图工具修复对应完整图片，再检查相邻姿势和镜头；不能把整图镜像或贴一块屏幕/文字当作默认修复方式。

## 场景素材与分层合成

按生图路由创作角色、场景、道具、姿势帧、特效与封面图片并整理到画布；使用合适的图片整理工具处理统一尺寸、定位和输出规格，像素形式另按其网格规范整理，动画软件或本地脚本组织图层与时间轴。

1. 先依据场景活动、人物调度与互动建立完整构图，再确定背景、完整角色姿势、独立道具及特效等合成单元，不默认采用背景前并排站立的双人布局。背景、角色与道具的透视、光照、色彩和所选美术语言一致；角色身体不拆成待拼接的局部素材。
2. 每个固定机位制作一张稳定的背景底图，按实际遮挡需要组织前景或蒙版。完整角色姿势、独立移动的道具和环境特效分别组织，静止内容尽量复用；分层用于场景合成与遮挡，不用于拼装角色的嘴、头或肢体。
3. 为角色建立可复用的完整姿势图片。说话、闭口、表情、手势或转头的每种变化都输出完整角色，在动画中替换整张姿势图；不单独生成嘴形、手臂、头部等片段供后续拼接。
4. 同一姿势组使用相同素材画布、角色比例和定位基准，选定适合动作的脚底、髋部或支点作为锚点，预留容纳整组动作的空间。换帧保留透明留白及锚点，不逐帧裁到不同外接框或自动居中；角色整体位移单独安排，对齐校验按下方规范执行。
5. 角色、活动道具和特效使用透明背景 PNG；场景底图可使用不透明 PNG。轮廓及透明边缘清楚，角色通过接触阴影、遮挡及一致光照自然融入场景，避免白边、杂色边、模糊羽化和贴纸感。
6. 握持、递物或接触动作在完整姿势中表现正确的手、道具与身体关系，随角色运动的手持道具一并生成。转交前后明确道具归属，独立道具层与姿势中的道具不能重复显示；复杂互动可生成统一机位的完整镜头动作图片。角色经过桌椅等物体时用场景前景或蒙版处理遮挡，不拆出角色肢体重新拼装。
7. 背景在同一镜头内保持稳定；只有剧情需要的局部内容发生变化，例如灯光、火焰、烟雾、门扇或移动物体。
8. 角色和道具先按镜头所需尺寸及所选形式规范统一整理。需要改变角度、形体或景别时制作对应完整图片；像素形式保持逻辑网格与像素密度，卡通形式的整图变换保持线条、比例及运动稳定，不用随意拉伸代替新姿势。
9. 生图工具输出的完整姿势图片先校准同组尺寸、轮廓和定位，再进入动画工程。保存通过检查的素材与参考关系；编辑问题姿势时仍输出完整图片，不因一个姿势失败而重建整个场景。
10. 为每个重复出现的地点建立场景编号、空间设定和经过检查的基准背景，登记固定结构：墙面与天花板、门窗位置、灯具实体、插座、主要家具布局及固定装饰。不同机位使用同一空间设定；只制作剧情实际需要的机位与时间版本。
11. 固定结构与可变状态分开管理。昼夜、天气或开关变化可以改变亮度、色温、投影、窗外环境及灯具发光状态，不能无依据地增删或移动灯具、门窗和家具。灯具实体保留在固定结构中，发光效果作为独立状态或图层处理。
12. 环境状态版本优先通过所选生图工具编辑基准背景，新机位依据同一空间设定创作并核对固定结构。场景表记录环境状态，角色与道具的动态状态按 [动作与表演](visuals-and-performance.md#动作与表演) 管理，只保留本剧情需要的属性；变化须有依据及生效时间。
13. 校验时逐镜头对照场景设定，并将同一地点的日夜版本、相邻镜头和重复出现的镜头并排比较。按房间中的实际空间位置核对结构，不能只比较画面左右；合理的镜头裁切、透视或遮挡可以使物体不可见，但不能改变其存在与位置。
14. 光照和投影对应故事中合理的光源，结构本身与照明表现分别管理。状态或机位变化不无故增删对象；可见性变化须能由裁切、遮挡、视角或剧情事件解释。

### 完整动作帧与对齐校验

1. 完整动作帧是可直接用于换帧的整张图片。角色姿势图片包含完整角色轮廓及随动作一起表现的道具，保留透明画布和动作余量，不能截断伸出的手、脚或道具。采用完整镜头动作图片时，保留该镜头应有的场景与互动关系；特写按镜头构图制作，不以身体碎片拼接成画面。
2. 清单确认后，先确定标准人物参考图、当前机位的完整首尾关键帧、素材画布宽高、角色比例、朝向和锚点位置。首尾及缺失关键画面入画布并经确认后，再生成中间连续帧：以上一张合格帧为编辑目标，标准图/镜头基准核对固定属性，尾帧约束终点，明确本帧细微变化。新机位或景别建立相应基准，同组不随表情或手势改变画布规格与比例。
3. 图片请求明确“输出完整姿势图片、保留整张画布、相同角色比例与锚点、只改变指定动作或表情”。即使只编辑嘴形或手势，也返回完整图片；不要请求裁切后的局部输出、多格拼图或尺寸各异的部件。
4. 工具返回尺寸不符时，保留原始结果，按所选形式的尺寸规范和整组一致的比例与定位规则整理，必要时补足透明留白。禁止逐帧按内容边界独立缩放、紧裁或居中；角色比例、轮廓或锚点不能合理对齐时，编辑或重生成问题帧。
5. 合成前读取每帧实际宽高及透明通道，逐张检查动作范围、角色比例、锚点、肢体数量/连接和道具接触，并叠加或快速切换同组图片，检查非动作区域是否无故漂移、头身转动是否协调。按 [肢体与头身动作检查](visuals-and-performance.md#肢体与头身动作检查) 复查实际换帧；叠加图仅用于检查，不作为正式姿势输出。全组应能按同一定位规则直接替换，无需另行拼接身体部位或逐帧重新定位；有意的整体位移记录在时间轴中。
6. 素材清单记录姿势组、标准人物图、镜头首尾帧及其确认版本、关键/中间帧角色、各帧路径/版本与上一合格帧、目标尾帧和动作进度、固定属性、统一画布/比例/锚点与检查结果。修复后复查有关完整帧和依赖该帧生成的后续帧及动作段；旧的局部部件不能继续作为当前姿势帧使用。

### 标准参考图与上一帧微调

1. 人物、场景和关键道具清单确认后，先生成并检查完整标准人物图，固定脸型、五官、发型、身体比例、服装款式/颜色/纹理及关联道具，再建立当前镜头首帧与关键变化的尾帧，固定背景、构图、机位、光源、光照和画布/锚点。尾帧可从首帧编辑为目标终态，属于预先规划的关键帧，允许与首帧有较大动作差异；它不等于连续序列中紧接首帧的下一张。标准图适合时可复用为首帧，保存明确版本，按 [画布流程](canvas-and-image-routing.md#逐级确认与首尾帧先行) 补齐缺失关键画面并取得画布确认。
2. 首尾关键帧确认后，规划两者之间的动作路径、必要接触/转折姿势、帧序、每帧目标进度及允许变化区域，再按播放顺序生成中间帧。以刚通过检查的上一帧为编辑目标，不将中间帧独立从同一首帧重画冒充逐帧推进。工具支持多张参考时，将上一帧标明为编辑目标、标准图/镜头基准用于一致性、尾帧用于终点约束；只支持单张目标时使用上一合格帧，并在规划与检查中对照这些参考，不编造接口字段。
3. 提示明确“严格以上一帧为基础，只将指定动作推进一小步，保留其他内容”。锁定脸部、身体比例、服装设计、背景、机位、光源、光照和非动作区域；运动部位的关联衣袖、接触与必要局部关系随动作正确变化。比如举手只改变手臂及关联衣袖的姿势，肩部连接、头部、躯干、腿脚与背景保持固定，不新增转头、眨眼或其他无关动作。每次仍输出完整角色及关联道具或完整镜头图片，不裁切或拼接肢体。
4. 每生成一张中间帧，同时与上一合格帧、标准图/镜头基准及目标尾帧比较：动作按计划小幅推进并接近终态，固定属性无漂移，肢体与道具关系正确。可用叠加、固定区域对比和快速切换辅助定位，再实际查看结果；提示词写了保持一致不代表已经做到。当前帧不合格时从上一合格帧修复后继续，不沿用错误帧。发现累积漂移时回查最早问题，修复后核对其后续依赖，必要时重生成受影响序列。
5. 固定背景可在合成工程中复用同一背景图层，角色完整帧保持统一透明画布与定位，避免重新生成静态场景造成漂移；采用完整镜头图片时逐帧检查背景。无论采用哪种合成单元，都保留上一帧来源、标准参考版本、动作变化说明、生成结果与检查状态，最终按顺序直接换完整图。
6. 接近预先生成的尾帧时，检查最后中间帧与尾帧的姿势、接触、状态和步幅是否自然衔接；尾帧仍合格时直接采用，不机械再生成另一张尾帧。存在跳跃时修复或补齐过渡，不在结尾突然跳姿势或用淡化掩盖。需要实质改变已确认尾帧、动作范围或用户指定总帧数时，先形成具体调整方案并更新有关确认。

#### 缓慢举手的 12 帧示例

本例交付 `F01` 至 `F12` 共 12 张有效不同的完整动画图片：先生成自然下垂的首帧 `F01` 和计划举手姿势的尾帧 `F12`，放入画布检查并确认，再补 `F02` 至 `F11`。将起止动作规划为 11 次小幅推进，逐帧登记手肘、手腕位置与关节角度；中间帧各以前一合格帧为编辑目标，并以 `F12` 为终点，最后检查 `F11 → F12` 的衔接。标准图适合作为首帧时可复用为 `F01`，不额外计为第十三张动画帧。举手方向、起止位置与整体时长按本镜头表演确定。

单次中间帧编辑提示可写：“以上一帧 `Fxx` 为编辑目标、标准人物图和镜头基准为一致性参考，以已确认尾帧 `F12` 的举手姿势为终点，生成下一张中间帧。保持脸部五官、发型、身体比例、服装款式/颜色/纹理、头部/躯干/腿脚、背景、机位、构图、光源和光照完全一致。只让举手侧手臂沿既定路径向终点移动一小步，关联衣袖随动，关节连接和手指结构正确；输出同尺寸、同定位的完整图片。”每次补充帧编号、目标位置与相对上一帧变化，不一次请求多格拼图代替逐帧图片。

逐张检查全部 12 帧及相邻切换，再以完整序列制作播放预览。12 指独立动画图片数量，不是 12 个输出帧或 12 fps；成片仍按 24 fps 输出，每张可保持多个输出帧以表现缓慢动作。用户明确要求共 12 帧时，在这 12 张内修复过渡、调整动作步幅和停留；需要改变帧数或动作范围的实质取舍先提供具体方案。其他变化继续遵守至少六张有效不同图片的下限。

### 变化单元与至少六张有效图片

1. 变化单元指指定人物或对象的一次可见状态变化或一个完整运动循环，例如平静转为惊讶、抬手递物、转身、嘴形开合、开门、物件翻转或环境效果变化。按实际表演目的划分，不把整段视频中互不相关的变化合成一组来凑数；没有变化的背景、静态道具和停留画面无需无故制造运动。
2. 每个完整变化序列至少六张有效不同图片，样片、正式动画及两种画风均适用；首尾关键帧规划阶段可先只有两张，但不能据此判定连续动作通过或进入最终采用。补间后以起始状态、必要过渡/接触及结束状态组成完整序列，首尾满足有效差异且实际采用时计入；循环返回同一首帧不重复计数。未采用候选、复制文件、重复播放、延长停留或改变编码/分辨率均不能增加计数。
3. 有效差异须发生在当前变化元素上。六张图片只有背景或无关物件变化，而角色表情/动作仍只在两张图之间切换，不能算该角色变化满足下限。多个元素可以共用同一完整镜头序列，但须分别核对每个变化单元有至少六张承载其变化的有效图片，不机械穷举所有表情、嘴形和手势组合。
4. 角色的表情、嘴形、转头、手势和身体变化始终生成完整角色及关联道具，复杂互动可生成完整镜头图片；独立道具与环境效果生成对应完整对象/效果帧，不生成角色身体碎片拼接。各序列固定画布、比例、锚点和机位关系；帧间变化服务于动作路径和状态过渡，不靠随机抖动或无依据形变制造差异。
5. 在动作表/素材清单登记变化单元标识、所属人物/对象、起止状态或循环目的、对应图片路径/版本、实际帧序、有效不同图片数量和检查结果。合成前逐个核对数量及采用关系；不足六张时补生成必要完整图片并复查。达到六张仍有跳跃、接触缺步、身体异常或状态不连续时继续补帧/修复，不能仅凭数量放行。

### 图片创作与校验

1. 先根据镜头和表演需求规划素材。每项生成明确用途、主体、构图、选中的视觉形式、色彩与光照、完整图片的基准关系、需保持的画布/比例/锚点和透明背景要求；涉及阅读、展示或递交道具时按 [视线与道具朝向](visuals-and-performance.md#视线阅读面与道具朝向) 写清可读面、视线与机位，只补充能改善画面与叙事的细节。
2. 区分新图创作与已有图片编辑，明确输入图片是标准人物图、镜头基准还是编辑目标。编辑前查看完整目标，按当前接口传入实际画布来源节点或本地图片，不只在提示中描述参考。连续动作按 [上一帧微调](visuals-and-performance.md#标准参考图与上一帧微调) 使用上一合格帧，描述本帧动作进度及须保持的身份、结构、比例、背景、光照与构图，要求仍输出完整图片；生成后同时对照上一帧和标准参考检查。
3. 完整角色姿势、独立道具及特效素材请求真实透明背景并保留透明通道，完整背景和镜头画面可用不透明图片。生成后按完整帧规范校准同组尺寸、锚点和边缘，像素形式同时校验逻辑网格，不假定工具能直接输出指定的最终文件尺寸。
4. 实际查看生成结果，检查风格、美感、主体与构图、角色一致性、场景结构、肢体数量/连接、头身朝向、视线/道具朝向、关键文字和事实。针对问题继续使用所选生图工具编辑，合格部分复用；技术整理、文字排版与动画合成按 [主入口的工具分工](../SKILL.md#全流程约束) 执行。
5. 将原始结果与工程素材保存到作品目录，并按 [画布整理与同步](canvas-and-image-routing.md#统一导入与画布排列) 建立图片节点、排列序列，记录工具、参考、生成提示词、版本与采用关系。参数以实际工具说明为准；工具不可用时说明限制并继续可执行工作。
6. 不假定图片工具提供固定 seed、任意输出尺寸、自动骨骼绑定、逐帧连续运动或完整视频导出。只使用实际接口支持的字段；角色和场景一致性以图片与样片检查为准，运动由采用完整图片的本地工程控制。

## 美术与角色一致性

1. 先读取作品选中的形式规范：[常规像素](style-japanese-pixel.md) 或 [讽刺手绘卡通](style-satirical-cartoon.md)。固定角色、场景、道具、特效及封面的共同语言，具体尺寸、网格、线条及采样规则由所选形式规定。
2. 建立风格和角色参考，固定可辨识的脸型、发型、服装、配饰、主色和比例。表情、姿势、机位或心理特写变化持续引用同一身份设定。
3. 每个动作图片保留完整内容及同组尺寸、比例和定位基准，按前面的完整帧规范校验。日常表演与夸张特写可以有不同强度，保持身份、事实与剧情状态一致。
4. 根据时代、地点、角色身份和叙事重点组织建筑、服装、道具及光照。画面兼顾构图、色彩、美感和有取舍的细节，复杂程度服务于本镜头的理解和情绪。
5. 在最终输出和手机观看尺寸检查表情、动作、道具、信息视窗及空间关系，避免无依据的拉伸、关键内容裁断或拥挤。
6. 标题、字幕、气泡、计数器数字及说明文字预留构图位置，使用核对后的文字层独立排版，以清楚、美观、易读为准。封面按 [封面与发布](covers-and-publishing.md) 适配。

## 动作与表演

1. “姿势帧”是一张包含完整角色的动作图片，或用于整体换帧的完整镜头动作图片，多张输出帧可以复用同一姿势。姿势数量、姿势替换速度和成片输出帧率分别记录，不混为一个参数。
2. 每个表情转换、嘴形开合、手势、转身、走路或蹬车循环，以及道具/环境等可见变化单元，均先规划至少六张有效不同的完整图片，样片也遵守同一下限。仅生成剧情实际需要的序列与组合；六张不是成片图片数量上限，动作跨度过大、接触缺步或播放跳跃时按下方多帧方法继续增加完整过渡图片。
3. 为每个动作规划准备、发生、接触和结束的必要姿势，按动作复杂程度补充。关键姿势必须让观众看懂意图、力量方向及结果。
4. 同一姿势保持到下一姿势图片直接替换，按同组画布和锚点换完整图，表现有意设计的有限帧节奏。姿势之间不使用整图交叉淡化，避免人物、手和道具重影。
5. 可先用每秒六至十二次姿势替换测试动作段，再按语速、动作速度及情绪调整；姿势持续时间以输出时间轴中的整数帧记录。对白停顿或动作关键点可以延长，不将整片机械设成统一换帧速度。
6. 例如在 24 fps 时间轴中，每张动作姿势持续三个输出帧，会形成每秒八次姿势替换。动作拥有几张独立画与每秒换几次姿势是不同参数，应分别记录。
7. 嘴形依据成片时间轴上的实际发声与停顿安排，停顿时适当闭口，笑声、喘息等采用对应的嘴形与表情。有限嘴形可按语义短段及已确认的声音活动区间安排，不凭转写文本编造逐字或音素时间。重要语句配合手势和听者反应，避免对白期间均匀开合。配音或工程时序改变后，按 [配音与音频](voice-and-audio.md) 更新相关表演与字幕。
8. 身体允许少量呼吸、点头、转头或姿势变化，但幅度有目的。小幅转头可保持身体不动；大幅改变朝向时按下方 [肢体与头身动作检查](visuals-and-performance.md#肢体与头身动作检查) 设计肩、躯干及下肢的配合。不要给全部角色持续添加相同频率的上下弹跳。
9. 循环依据动作结构组织，往返形式只用于适合往返的动作。姿势内部的锚点、比例和衔接稳定，整体位移另行安排；复用时检查当前形态、位置、接触与遮挡，必要时补充姿势。循环是否保持状态或产生结果由剧情决定，静止背景保持稳定。
10. 持续运动的姿势、位移和速度相互匹配，支撑点、接触点和运动路径符合动作条件。角色与关联道具协同运动，避免滑步、穿透和无意漂移。
11. 单次动作完成后进入稳定状态、人物反应或下一动作；再次发生须有相应的剧情依据。停留、持续动作与阶段切换按表演需要选择。
12. 普通动作靠完整姿势换帧及场景图层合成实现；烟雾、火焰、闪光等环境特效可按统一画布制作完整特效帧并独立循环，节奏与角色表演分开控制。
13. 镜头移动与角色换帧分别安排。镜头平移时，场景、角色及前景共同遵循一致运动，按所选形式保持定位与边缘稳定。景别变化使用对应完整素材，像素形式遵守固定像素密度与整数坐标，卡通形式可按其规范安排整图推拉；最终输出按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 完成。
14. 按“完整基准→完整姿势图生成或编辑→整组对齐校验→动作时间表→整图换帧与场景合成”组织制作。所选生图工具提供完整画面素材，即梦画布保存可观察的参考与帧序，可复用的合成工程或脚本控制换帧、循环、位移与镜头时间。

### 用多帧切换补足连续动作

没有直接生成连续动画或连续动作视频的能力时，按生图路由生成更多完整姿势或完整镜头图片，整理到画布并由本地合成工程按顺序替换，模拟连续动画。连续视频生成接口不是完成本流程的前提；实际活动、道具接触与动作结果仍须完整呈现。

1. 先确定动作起点、终点及必须发生的接触/状态变化，再拆出关键姿势和必要过渡。例如递文件可表现为“伸手取件 → 握住抬起 → 移向对方 → 双方接触 → 接收者握住 → 递出者松手 → 接收者收回”；按机位和动作需要进一步补帧，复杂互动可用整张镜头图片，不能只在递交前后两张静图之间跳切。
2. 先建立标准人物图和各变化的首尾关键帧，入画布、补齐缺失关键画面并取得确认，再按 [上一帧微调](visuals-and-performance.md#标准参考图与上一帧微调) 顺序生成中间帧。每张中间帧以前一合格结果为目标，标准图/镜头基准核对固定属性，尾帧约束终点。明确动作进度、头身与手脚配合、握持/道具归属及画布/比例/锚点；每张仍是完整角色与关联道具或完整镜头，失真帧先修复，不拆身体部件拼接。
3. 将每个变化单元补齐为至少六张有效不同图片的完整序列，检查全部相邻切换及进入已生成尾帧的衔接。姿势跳跃、转身缺步、接触突然发生或移动跨度过大时，在对应位置补充完整过渡图片再复查；以动作过程与连续性判断是否足够。用户指定确切数量时在其范围内规划与修复，需要实质调整数量时提供具体方案，不用增加输出帧数代替新动作图片。
4. 在动作表与时间轴记录图片顺序、每张的持续输出帧数、接触/变化时刻和必要整体位移。正式输出仍为 24 fps，独立图片可以各保持一个或多个输出帧，按动作速度、停顿和实际配音调整。重复同图只增加停留时长；补帧须增加实际不同的姿势。姿势仍直接整图替换，不用交叉淡化、随意拉伸或镜头推拉代替缺失动作。
5. 循环只用于剧情中确实重复的运动，检查首尾衔接、支撑脚、位移与道具状态；拿取、递交、落座等单次动作完成后进入其结果状态，不能靠循环少量帧反复重置。角色和环境继续遵守 [动作与场景交互](visuals-and-performance.md#动作与场景交互)、肢体及视线/道具朝向要求。
6. 逐个核对变化单元至少六张有效不同图片，再逐张查看全部采用图片，按动作顺序检查相邻帧、关键接触与循环首尾，并查看合成预览；具备播放能力时正常速度与慢速复查。发现问题先修复或补帧，再复查完整动作段及前后镜头。素材记录保存变化单元与图片的对应、有效数量、帧序、补帧位置及检查结果，数量达标本身不代表连续性已通过。

### 肢体与头身动作检查

1. 以固定角色设定为依据，逐张检查所有实际采用的完整姿势图片。普通人类角色的两条手臂、两条腿及相应手脚数量与归属稳定，不出现多手、多脚、缺肢、粘连、悬空手掌或从错误位置长出的肢体。卡通手指可按既定画法简化，不能在同组无故改变；合理的遮挡与镜头裁切不算缺肢，多人重叠时核对每只手脚属于谁，不为凑数量补画被遮住的部位。
2. 检查肩、肘、腕、髋、膝、踝的连接和弯曲方向，颈部与躯干连接、身体比例、左右手脚身份、接触与重心是否可信。坐、站、走、拿物和递物各有相应支撑；避免手穿过道具、腿穿过椅子、支撑脚滑动或身体悬浮。风格化夸张须符合角色画法和表演意图，不能掩盖无依据的结构错误。
3. 根据动作目标判断头身配合。侧目、小幅回头或点头可以只动头；人物要转向身后、面向另一人、转身离开或改变行走方向时，肩线、胸部、骨盆、支撑脚及持物手须按动作需要配合，不能身体和脚仍保持原方向，却让头单独跳到明显不合理的朝向。不机械要求头、身、脚同时同幅转动，可安排先看向目标、肩身跟随、重心转移和脚步调整的必要完整姿势。
4. 生成转向姿势时明确动作起点、终点及各部位配合，例如“由正面转向右侧离开，头和肩胸转向右侧，骨盆随重心变化，支撑脚与迈步脚匹配，保持两臂两腿及握物关系”。不能只要求“转头”来代替整个转身动作，也不能只旋转或替换头部素材；仍输出完整角色及关联道具，或完整镜头图片。
5. 单图检查后，按播放顺序查看每组相邻姿势、动作转折和循环首尾，在合成预览中检查是否出现手脚增减、左右互换、头身脱节、朝向突跳、重心跳变或轮廓残留。环境支持时正常速度与慢速播放动作段；静态全检、换帧检查和实际播放分别记录，抽看少量图片不能替代采用姿势的逐张检查。
6. 发现异常先定位来源。原始图片的结构或动作错误，用所选生图工具编辑或重生成对应完整姿势，必要时补充过渡姿势，并保持同组画布、比例与锚点；原图正确而合成出现多手多脚时，检查旧姿势是否未移除、图层是否重复、交叉淡化或遮挡是否错误，修复工程引用和换帧关系。不要靠遮住错误、切掉动作或拼接肢体掩盖问题。
7. 保存问题对应的角色/姿势/镜头编号、来源、修复版本与复查结果，异常素材在修复通过前不进入正式采用清单。修复后复查相邻姿势、完整动作段、道具关系和导出中的关键换帧位置；保留仍合格的其他素材。缺少可执行的播放检查时如实标注，不能将提示词已写入或成功编码当作身体动作已核验。

### 情境推理与表演设计

1. 每个场景先判断“人物为什么这样做、当前正在做什么、会接触或使用什么、空间怎样影响行动、行动或变化如何发生、会带来什么结果、接下来怎样反应”。按 [动作与场景交互](visuals-and-performance.md#动作与场景交互) 将推演落实为实际表演；依据来自人物动机、生活经验和故事设定，必要的因果关系能被观众理解。
2. 根据叙事目的选择单次、持续、重复、过渡或静止表演，决定需要展示的关键步骤与变化。动作复杂度和细节量服务于理解、情绪与节奏，简单场景使用简洁设计。
3. 对影响后续剧情或观看理解的人物、道具和环境，记录身份及关键状态。位置、归属、形态、数量、可用性、情绪或关系等属性按实际需要选择；状态在相应变化发生时更新，跨镜头依据对应剧情时刻延续。
4. 区分动作形式与剧情结果。姿势可以复用，结果是否持续、累积、消耗或恢复由情境决定；接触、转移和变化的前后关系合理。角色动作、关联对象和视觉反应相互支持，不能因循环复用而意外改变事实。
5. 重复动作的起止与变化依据当前情境判断。条件改变、目标达到或发生中断时，安排合适的反应、结束或衔接；已经发生的结果保留，尚未发生的结果不提前呈现，恢复表演时从对应状态继续。
6. 如需展示数量、进度或比较，先定义信息含义、来源、单位、范围和更新方式；必要时明确初值、累计及重置规则。区分结果数量与动作次数，同一事实不因换帧、换镜头或回放重复计算。静态信息可直接引用已核对的依据，动态信息随对应变化更新。
7. 时间压缩、跳跃或回忆服务于叙事，区分故事中的时间与成片播放顺序。省略过程保留可理解的前后关系，回忆呈现相应历史状态；停留时长的改变本身不意味着新增动作或结果。
8. 将关键动作、反应、状态变化和信息展示落实到成片时间轴，协调配音、镜头、表情与音效。查看实际关键帧、合成预览及环境支持的连续播放，验证“意图—表现—结果”是否成立；按覆盖范围记录结果，调整需要的步骤、素材和节奏，变更后复查关联内容。

按剧情复杂度整理场景与表演状态记录，可与镜头及动作表合并；只填写实际影响制作和连续性的内容：

| 推理与记录内容 | 作用 |
| --- | --- |
| 叙事目的、人物意图与情境条件 | 判断行为依据及表现重点 |
| 场景活动、互动对象、关键接触、人物调度、动作结果与反应、变化条件与衔接 | 组织人与道具/空间的交互及表演，检查动作是否实际发生 |
| 相关人物、道具、环境与前后状态；阅读/展示时的视线、可读面、机位与可见面 | 保持身份、空间、物件朝向和因果连续 |
| 实际使用的数据定义与更新依据 | 校验信息显示与比较 |
| 对应剧情时刻、镜头与成片时刻 | 协调时间组织及声音 |
| 选用素材、版本与关联关系 | 支持复用、修改与复查 |
