# 视觉与表演

在镜头构思、图片制作、场景连续性、信息可视化和动作设计时读取。本文件规定故事画面、角色、道具、特效与封面共同使用的美术和表演语言。

采用作品选中的 [日系唯美像素](style-japanese-pixel.md) 或 [讽刺手绘卡通](style-satirical-cartoon.md) 形式。两者共用完整动作图片、场景连续性和有限动画组织：以少量可复用的完整角色姿势帧、角色移动、道具变化、环境特效和镜头剪辑演出剧情，嘴形、表情和手势包含在完整姿势图片中。下面的姿势数量与换帧速度是样片测试起点，按本剧的实际表演和声音调整。

每个场景先理解叙事作用、人物意图和情境条件，再自主选择表演与信息表达。采用剧本和输出范围见 [主入口](../SKILL.md)，素材的版本、交接和续作见 [阶段衔接与续作](handoff-and-resume.md)。

Agent 使用 Image Gen 制作美术内容，使用图片读取与本地程序进行技术整理、场景合成和检查视图。实际图片创作、可重复工程和检查依据按 [制作执行与能力边界](production-execution.md) 分工，先用完整基准和代表性动作小组验证可用性，再展开全片素材。

内容：镜头与信息表达；场景素材与分层合成；所选美术与角色一致性；动作与表演。仅用到其中一部分时阅读相应章节。

## 镜头与信息表达

1. 阅读剧本与参考，理解主题、人物关系、目标、情绪和关键转折，保留核心剧情、对白含义及结局。
2. 将剧本拆成“场景→镜头→动作段→姿势帧”。判断每段需要观众理解或感受到什么，再选择建立环境、对白、反应、动作、细节揭示或转场等镜头组织方式。
3. 表演结合说话内容、潜台词、对象和反应设计。一段对白可以延续同一构图，也可以跨越多个动作；镜头切换由叙事需要决定，不按台词数量或说话人机械分配。
4. 景别、机位与构图服务于注意力和情绪，空间关系与视线方向清楚。改变视角时，角色比例、环境结构和对象身份仍依据同一设定。
5. 每个场景都推演人物行为与环境变化的依据。根据动作性质选择关键步骤、反应和状态，具体方法按 [动作与表演](visuals-and-performance.md#动作与表演) 执行，不为了复用动作而删改剧情。
6. 总时长依据定稿配音、动作和情绪停顿确定。复杂信息保留理解与反应时间，具体定时按 [配音与音频](voice-and-audio.md) 核定。
7. 信息可视化先识别理解难点，再选择最合适的表达方式：数量或进度可用计数器、刻度或排列；差异可用并置对照；关系可用构图与视线；细节可用局部特写或放大。仅在有助于理解时使用，形式与时代、场景及选中的美术语言协调。
8. 创意体现在信息如何融入剧情和表演。安排出现、变化与收束的时机，控制同时展示的信息量，重要内容留足阅读时间；数值、单位和比较口径准确，目标、假设与已经发生的结果区分清楚。
9. 细节视窗与特写依据原对象制作，按所选形式的尺寸与排版规范呈现对应的形状、文字和含义，不改变事实。与主画面保持明确关系，手机尺寸下可读，不遮挡主要表演或字幕。
10. 根据实际使用的信息设计保存内容依据、形式、关联镜头或变化时刻及素材来源。动态数据显示引用 [动作与表演](visuals-and-performance.md#动作与表演) 的状态记录，其他信息标明来源；场景内道具与说明性图层分别组织。

## 场景素材与分层合成

使用 Image Gen 创作角色、场景、道具、姿势帧、特效与封面图片；使用合适的图片整理工具处理统一尺寸、定位和输出规格，像素形式另按其网格规范整理，动画软件或本地脚本组织图层与时间轴。

1. 先建立完整的场景构图，再确定背景、完整角色姿势、独立道具及特效等合成单元。背景、角色与道具的透视、光照、色彩和所选美术语言一致；角色身体不拆成待拼接的局部素材。
2. 每个固定机位制作一张稳定的背景底图，按实际遮挡需要组织前景或蒙版。完整角色姿势、独立移动的道具和环境特效分别组织，静止内容尽量复用；分层用于场景合成与遮挡，不用于拼装角色的嘴、头或肢体。
3. 为角色建立可复用的完整姿势图片。说话、闭口、表情、手势或转头的每种变化都输出完整角色，在动画中替换整张姿势图；不单独生成嘴形、手臂、头部等片段供后续拼接。
4. 同一姿势组使用相同素材画布、角色比例和定位基准，选定适合动作的脚底、髋部或支点作为锚点，预留容纳整组动作的空间。换帧保留透明留白及锚点，不逐帧裁到不同外接框或自动居中；角色整体位移单独安排，对齐校验按下方规范执行。
5. 角色、活动道具和特效使用透明背景 PNG；场景底图可使用不透明 PNG。轮廓及透明边缘清楚，角色通过接触阴影、遮挡及一致光照自然融入场景，避免白边、杂色边、模糊羽化和贴纸感。
6. 握持、递物或接触动作在完整姿势中表现正确的手、道具与身体关系，随角色运动的手持道具一并生成。转交前后明确道具归属，独立道具层与姿势中的道具不能重复显示；复杂互动可生成统一机位的完整镜头动作图片。角色经过桌椅等物体时用场景前景或蒙版处理遮挡，不拆出角色肢体重新拼装。
7. 背景在同一镜头内保持稳定；只有剧情需要的局部内容发生变化，例如灯光、火焰、烟雾、门扇或移动物体。
8. 角色和道具先按镜头所需尺寸及所选形式规范统一整理。需要改变角度、形体或景别时制作对应完整图片；像素形式保持逻辑网格与像素密度，卡通形式的整图变换保持线条、比例及运动稳定，不用随意拉伸代替新姿势。
9. Image Gen 输出的完整姿势图片先校准同组尺寸、轮廓和定位，再进入动画工程。保存通过检查的素材与参考关系；编辑问题姿势时仍输出完整图片，不因一个姿势失败而重建整个场景。
10. 为每个重复出现的地点建立场景编号、空间设定和经过检查的基准背景，登记固定结构：墙面与天花板、门窗位置、灯具实体、插座、主要家具布局及固定装饰。不同机位使用同一空间设定；只制作剧情实际需要的机位与时间版本。
11. 固定结构与可变状态分开管理。昼夜、天气或开关变化可以改变亮度、色温、投影、窗外环境及灯具发光状态，不能无依据地增删或移动灯具、门窗和家具。灯具实体保留在固定结构中，发光效果作为独立状态或图层处理。
12. 环境状态版本优先通过 Image Gen 编辑基准背景，新机位依据同一空间设定创作并核对固定结构。场景表记录环境状态，角色与道具的动态状态按 [动作与表演](visuals-and-performance.md#动作与表演) 管理，只保留本剧情需要的属性；变化须有依据及生效时间。
13. 校验时逐镜头对照场景设定，并将同一地点的日夜版本、相邻镜头和重复出现的镜头并排比较。按房间中的实际空间位置核对结构，不能只比较画面左右；合理的镜头裁切、透视或遮挡可以使物体不可见，但不能改变其存在与位置。
14. 光照和投影对应故事中合理的光源，结构本身与照明表现分别管理。状态或机位变化不无故增删对象；可见性变化须能由裁切、遮挡、视角或剧情事件解释。

### 完整动作帧与对齐校验

1. 完整动作帧是可直接用于换帧的整张图片。角色姿势图片包含完整角色轮廓及随动作一起表现的道具，保留透明画布和动作余量，不能截断伸出的手、脚或道具。采用完整镜头动作图片时，保留该镜头应有的场景与互动关系；特写按镜头构图制作，不以身体碎片拼接成画面。
2. 生成一组姿势前先确定基准图片、素材画布宽高、角色比例、朝向和锚点位置。各帧以同一完整基准为参考，清楚说明动作变化及必须保持的条件。新机位或景别建立相应基准，同一组内不随表情或手势改变画布规格与比例。
3. 图片请求明确“输出完整姿势图片、保留整张画布、相同角色比例与锚点、只改变指定动作或表情”。即使只编辑嘴形或手势，也返回完整图片；不要请求裁切后的局部输出、多格拼图或尺寸各异的部件。
4. 工具返回尺寸不符时，保留原始结果，按所选形式的尺寸规范和整组一致的比例与定位规则整理，必要时补足透明留白。禁止逐帧按内容边界独立缩放、紧裁或居中；角色比例、轮廓或锚点不能合理对齐时，编辑或重生成问题帧。
5. 合成前读取每帧实际宽高及透明通道，逐张检查动作范围、角色比例、锚点和道具接触，并叠加或快速切换同组图片，检查非动作区域是否无故漂移。全组应能按同一定位规则直接替换，无需另行拼接身体部位或逐帧重新定位；有意的整体位移记录在时间轴中。
6. 素材清单记录姿势组、采用基准、各帧路径及版本、统一画布、比例、锚点与检查结果。修复后复查有关完整帧和动作段；旧的局部部件不能继续作为当前姿势帧使用。

### Image Gen 创作与校验

1. 先根据镜头和表演需求规划素材。每项生成明确用途、主体、构图、选中的视觉形式、色彩与光照、完整图片的基准关系、需保持的画布/比例/锚点和透明背景要求；只补充能改善画面与叙事的细节。
2. 区分新图创作与已有图片编辑，明确输入图片是角色基准、场景基准还是编辑目标。编辑本地图片前通过可用的图片查看工具读取完整目标，按当前 Image Gen 接口传入图片。描述本次变化及须保持的身份、结构、比例和构图，要求仍输出完整图片；新姿势优先依据通过检查的基准，检查结果是否满足条件。
3. 完整角色姿势、独立道具及特效素材请求真实透明背景并保留透明通道，完整背景和镜头画面可用不透明图片。生成后按完整帧规范校准同组尺寸、锚点和边缘，像素形式同时校验逻辑网格，不假定工具能直接输出指定的最终文件尺寸。
4. 实际查看生成结果，检查风格、美感、主体与构图、角色一致性、场景结构、关键文字和事实。针对问题继续使用 Image Gen 编辑，合格部分复用；技术整理、文字排版与动画合成按 [主入口的工具分工](../SKILL.md#全流程约束) 执行。
5. 将选用的原始结果与工程素材保存到工作区，使用清楚的文件名与版本，保留参考、生成提示词和对应关系。参数以实际工具说明为准；工具不可用时说明限制并继续可执行工作。
6. 不假定图片工具提供固定 seed、任意输出尺寸、自动骨骼绑定、逐帧连续运动或完整视频导出。只使用实际接口支持的字段；角色和场景一致性以图片与样片检查为准，运动由采用完整图片的本地工程控制。

## 美术与角色一致性

1. 先读取作品选中的形式规范：[日系唯美像素](style-japanese-pixel.md) 或 [讽刺手绘卡通](style-satirical-cartoon.md)。固定角色、场景、道具、特效及封面的共同语言，具体尺寸、网格、线条及采样规则由所选形式规定。
2. 建立风格和角色参考，固定可辨识的脸型、发型、服装、配饰、主色和比例。表情、姿势、机位或心理特写变化持续引用同一身份设定。
3. 每个动作图片保留完整内容及同组尺寸、比例和定位基准，按前面的完整帧规范校验。日常表演与夸张特写可以有不同强度，保持身份、事实与剧情状态一致。
4. 根据时代、地点、角色身份和叙事重点组织建筑、服装、道具及光照。画面兼顾构图、色彩、美感和有取舍的细节，复杂程度服务于本镜头的理解和情绪。
5. 在最终输出和手机观看尺寸检查表情、动作、道具、信息视窗及空间关系，避免无依据的拉伸、关键内容裁断或拥挤。
6. 标题、字幕、气泡、计数器数字及说明文字预留构图位置，使用核对后的文字层独立排版，以清楚、美观、易读为准。封面按 [封面与发布](covers-and-publishing.md) 适配。

## 动作与表演

1. “姿势帧”是一张包含完整角色的动作图片，或用于整体换帧的完整镜头动作图片，多张输出帧可以复用同一姿势。姿势数量、姿势替换速度和成片输出帧率分别记录，不混为一个参数。
2. 对白可从两至三张含不同嘴形的完整姿势图开始，例如闭口、小幅张口和较大张口；手势可从两至四张完整姿势图开始；走路或蹬车循环可从四至六张完整关键姿势图开始。仅生成剧情需要的组合，不机械穷举嘴形与手势。以上是样片测试起点，按实际动作、声音和可读性调整，不设固定上限。
3. 为每个动作规划准备、发生、接触和结束的必要姿势，按动作复杂程度补充。关键姿势必须让观众看懂意图、力量方向及结果。
4. 同一姿势保持到下一姿势图片直接替换，按同组画布和锚点换完整图，表现有意设计的有限帧节奏。姿势之间不使用整图交叉淡化，避免人物、手和道具重影。
5. 可先用每秒六至十二次姿势替换测试动作段，再按语速、动作速度及情绪调整；姿势持续时间以输出时间轴中的整数帧记录。对白停顿或动作关键点可以延长，不将整片机械设成统一换帧速度。
6. 例如在 24 fps 时间轴中，每张动作姿势持续三个输出帧，会形成每秒八次姿势替换。动作拥有几张独立画与每秒换几次姿势是不同参数，应分别记录。
7. 嘴形依据成片时间轴上的实际发声与停顿安排，停顿时适当闭口，笑声、喘息等采用对应的嘴形与表情。有限嘴形可按语义短段及已确认的声音活动区间安排，不凭转写文本编造逐字或音素时间。重要语句配合手势和听者反应，避免对白期间均匀开合。配音或工程时序改变后，按 [配音与音频](voice-and-audio.md) 更新相关表演与字幕。
8. 身体允许少量呼吸、点头、转头或姿势变化，但幅度有目的。不要给全部角色持续添加相同频率的上下弹跳。
9. 循环依据动作结构组织，往返形式只用于适合往返的动作。姿势内部的锚点、比例和衔接稳定，整体位移另行安排；复用时检查当前形态、位置、接触与遮挡，必要时补充姿势。循环是否保持状态或产生结果由剧情决定，静止背景保持稳定。
10. 持续运动的姿势、位移和速度相互匹配，支撑点、接触点和运动路径符合动作条件。角色与关联道具协同运动，避免滑步、穿透和无意漂移。
11. 单次动作完成后进入稳定状态、人物反应或下一动作；再次发生须有相应的剧情依据。停留、持续动作与阶段切换按表演需要选择。
12. 普通动作靠完整姿势换帧及场景图层合成实现；烟雾、火焰、闪光等环境特效可按统一画布制作完整特效帧并独立循环，节奏与角色表演分开控制。
13. 镜头移动与角色换帧分别安排。镜头平移时，场景、角色及前景共同遵循一致运动，按所选形式保持定位与边缘稳定。景别变化使用对应完整素材，像素形式遵守固定像素密度与整数坐标，卡通形式可按其规范安排整图推拉；最终输出按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 完成。
14. 按“完整基准→完整姿势图生成或编辑→整组对齐校验→动作时间表→整图换帧与场景合成”组织制作。Image Gen 提供完整画面素材，可复用的合成工程或脚本控制换帧、循环、位移与镜头时间。

### 情境推理与表演设计

1. 每个场景先判断“人物为什么这样做、当前有哪些条件、行动或变化如何发生、会带来什么结果、接下来怎样反应”。推演依据来自人物动机、生活经验和故事设定，必要的因果关系能被观众理解。
2. 根据叙事目的选择单次、持续、重复、过渡或静止表演，决定需要展示的关键步骤与变化。动作复杂度和细节量服务于理解、情绪与节奏，简单场景使用简洁设计。
3. 对影响后续剧情或观看理解的人物、道具和环境，记录身份及关键状态。位置、归属、形态、数量、可用性、情绪或关系等属性按实际需要选择；状态在相应变化发生时更新，跨镜头依据对应剧情时刻延续。
4. 区分动作形式与剧情结果。姿势可以复用，结果是否持续、累积、消耗或恢复由情境决定；接触、转移和变化的前后关系合理。角色动作、关联对象和视觉反应相互支持，不能因循环复用而意外改变事实。
5. 重复动作的起止与变化依据当前情境判断。条件改变、目标达到或发生中断时，安排合适的反应、结束或衔接；已经发生的结果保留，尚未发生的结果不提前呈现，恢复表演时从对应状态继续。
6. 如需展示数量、进度或比较，先定义信息含义、来源、单位、范围和更新方式；必要时明确初值、累计及重置规则。区分结果数量与动作次数，同一事实不因换帧、换镜头或回放重复计算。静态信息可直接引用已核对的依据，动态信息随对应变化更新。
7. 时间压缩、跳跃或回忆服务于叙事，区分故事中的时间与成片播放顺序。省略过程保留可理解的前后关系，回忆呈现相应历史状态；停留时长的改变本身不意味着新增动作或结果。
8. 将关键动作、反应、状态变化和信息展示落实到成片时间轴，协调配音、镜头、表情与音效。查看实际关键帧、合成预览及环境支持的连续播放，验证“意图—表现—结果”是否成立；按覆盖范围记录结果，调整需要的步骤、素材和节奏，变更后复查关联内容。

按剧情复杂度整理场景与表演状态记录，可与镜头及动作表合并；只填写实际影响制作和连续性的内容：

| 推理与记录内容 | 作用 |
| --- | --- |
| 叙事目的、人物意图与情境条件 | 判断行为依据及表现重点 |
| 关键动作、反应、变化条件与衔接 | 组织表演及重复动作 |
| 相关人物、道具、环境与前后状态 | 保持身份、空间和因果连续 |
| 实际使用的数据定义与更新依据 | 校验信息显示与比较 |
| 对应剧情时刻、镜头与成片时刻 | 协调时间组织及声音 |
| 选用素材、版本与关联关系 | 支持复用、修改与复查 |
