# 叙事连续性与镜头衔接

在主剧本、分段、镜头规划、首尾帧画布、剪辑及成片自查时读取。使用当前采用的剧本和实际成果，检查观众能否理解事情怎样发生、为什么发生，以及结果如何引出下一步；不能以图片齐全或局部动作流畅代替完整事件成立。

## 三层连续性

| 层次 | 要核对什么 | 典型缺口 |
| --- | --- | --- |
| 事件与因果 | 目标/决定、执行、必要过程或合理省略、结果/交接、回应和下一步是否相互支持 | 说要送材料，下一场却已办完手续；未收到消息的人突然知道结果 |
| 镜头与场景 | 相邻镜头及跨场、跨段的时间、位置、人物、道具归属、任务进度和信息是否承接 | 出门时空手，到达却持有文件；上一镜还在递，下一镜物品已回到递出者手中 |
| 动作与帧 | 同一实际演出的变化，准备、移动、接触、受力、结果及相邻姿势是否自然 | 接收者没握住就松手；转身只换头；动作中间缺步 |

三个层次分别检查。补中间姿势不能修复缺失的交接或人物回应；补一个到达镜头也不能修复其内部的肢体异常。先判断缺口在哪一层，再修剧本、镜头、关键图或动作帧，避免对错误事件链不断补图。

## 关键事件要形成完整链条

按实际情节推演“目标或决定 → 启动执行 → 必要过程或有依据的省略 → 到达后的结果或交接 → 人物回应 → 下一步选择”。每个关键事件都能回答：谁因为什么做了什么，产生什么可确认的结果，谁看见或得知了结果，结果怎样影响后续行动。

这是一种完整性检查，不是强制六个镜头或六句对白。决定可以通过拿起材料出门来表现，回应可以是核对、停顿、退回物品或改变姿态；同一镜头能承载多个环节，简单活动无需复制全套结构。途中省略是可选剪辑手段，没有交接对象时检查行动结果。开放选择可以尚未决定，但须交代已发生的后果、当前处境及可选择的方向。

复用剧本动作说明、场景/镜头/动作表，建立一份随制作细化的连续性记录，不另维护重复正文。沿用现有稳定标识，`project_state.json` 指向统一入口；只记录影响本剧情的内容：

| 记录 | 必要内容 |
| --- | --- |
| 事件与前因 | 所属段/场景、参与者、当前目标、触发原因与行动所需条件 |
| 行动前后状态 | 时间/地点、人物位置、关键道具持有者与状态、任务进度；只有剧情使用时才记录数量或期限 |
| 执行与结果 | 实际行动、必要接触/受阻、完成/失败/待确认的结果；不把承诺或尝试登记为完成 |
| 信息与回应 | 谁通过什么看见、听见或接收到新信息，产生何种回应，如何支持下一步 |
| 呈现与省略 | 正文位置，进入制作后补对应镜头/关键图/素材/段内时刻；省略什么、两端线索和可推断依据 |

对照相邻事件：前一事件的结果状态是否能支持后一事件的起始条件？新增物品、位置、知识、权限或进度是否有来源？存在差异时，应有已演出事件或明确且合理的省略；不能靠制作者在记录里解释而让观众毫无线索。

## 省略过程时保留两端与关键事实

1. 可省略没有新信息、冲突或状态变化的重复走路、乘车、等待和重复操作。保留足以连接两端的线索，例如携物离开原处，切到目标地点的入口或现场人物，确认已到达；地点、时段或期限影响剧情时给出相应依据。不要求每次都拍完整路线或加时间字幕。
2. 省略区间不能暗中完成会改变成败、代价、道具归属、人物关系或信息判断的关键事件。关键交接、拒绝、发现、受阻与结果须实际呈现到能理解的程度；不能从“我去送”直接跳到“对方已同意”，也不能仅补一句“都办好了”替代主要戏剧事件。
3. 普通非关键结果可通过到达后的明确状态自然推断，但该状态必须可见、可信且不承载尚未交代的转折。若有两种会改变剧情的解释，补足区分线索；先修叙事缺口，再安排声音或转场。
4. 有意悬念、隐藏交接或事后揭晓仍要有真实可成立的事件顺序和后续兑现，记录隐藏范围及揭示位置。观众可以暂时不知道答案，但应知道人物正在等待什么或面临什么；审核稿向用户交代实际因果，不把遗漏伪装成悬念。

## 到达、交接、回应与下一步

- 到达：明确人到了哪里、面对谁、为何来，以及随身物品与任务状态。镜头可通过环境特征、人物关系和动作自然交代，不把切换背景当作到达已经清楚。
- 交接：区分递出、接触、接稳、松手、核对与接受。需要表示成功交付时，展示足够的接收行为和结果；拒收、部分接收、代收或待核验分别保留实际状态。接稳不自动等于认可内容，递出者也不能在没有依据时认为任务已获批准。
- 回应：相关人物先有看见、听见、阅读或被告知的依据，再回应新的事实。留出符合情境的感知与反应时间，不能让回应早于触发信息，也不能让人物凭观众已知的信息行事。沉默、犹豫或转身可以成立，但需让观众读懂其作用。
- 下一步：选择由刚发生的结果、阻碍、代价或新信息推动。允许角色犯错或拒绝行动，理由仍符合其知识与处境；新任务、新去向或情绪反转不能无故出现。无需每次口述计划，可通过明确行为表达。

## 首尾帧与剪辑怎样承接

先检查事件链和必要镜头覆盖，再生成或补齐关键画面。除单个动作首尾外，按剧情需要保留启动执行、离开、到达、关键接触、结果、回应与下一步的画面；这些功能可以合并，不机械为每项各生成一张。画布按事件及播放顺序串看，不能只查看每组内部首尾是否漂亮。

逐处检查“上一镜最后采用状态 → 下一镜最初采用状态”，以及事件、场景和上/中/下的边界。核对动作阶段、物件归属、人物位置/视线/朝向、空间出入、时间经过和信息先后。连续动作切镜时接住同一次行动，不能无故重做或跳过关键接触；合理的角度变化不等于物体在空间中换位。

同一镜头的中间帧仍以上一合格帧微调，检查进入既定尾帧的衔接。跨地点、跨时段或更换机位时建立对应镜头基准，不把无关首尾硬插值成穿墙、瞬移或背景变形。合理省略不需要为被省略的路程生成全部姿势；实际演出的可见变化仍按 [至少六张有效图片](visuals-and-performance.md#变化单元与至少六张有效图片) 完成，重复静帧和转场效果不计作补帧。

## 一个交接情节的完整示例

假设剧本要求小林送修改稿到前台，对方核对后发现缺少签字：

| 环节 | 可见内容 | 接续状态 |
| --- | --- | --- |
| 决定 | 小林听到前台要核对稿件，看向桌上的蓝色文件夹，决定送过去 | 文件夹仍在桌上，任务尚未执行 |
| 执行 | 他拿起蓝夹，离开办公室 | 小林持有文件夹，目的地已明确 |
| 途中省略与到达 | 省略无事发生的走廊路程，切到前台，他持同一蓝夹走近工作人员 | 地点改变有依据，携物和任务状态延续 |
| 交接与结果 | 小林递出，工作人员接稳，他松手；工作人员打开核对，指出签字栏空着 | 文件夹归工作人员暂持，已送到但尚未核验通过 |
| 人物回应 | 小林顺着对方所指看见空栏，停顿后确认漏签 | 他此时才得知缺项，不能此前就表现为知道 |
| 下一步选择 | 他决定回去补签；工作人员将蓝夹退回，他接稳后带走 | 退回动作明确，后续不能无故变成空手或已批准 |

具体情节按采用剧本创作，示例不授权增加缺签转折。若剧本本来是成功交接，展示实际接收与相应回应，再进入已有的下一步；不为凑结构制造障碍。

## 自查与修复顺序

1. 剧本：连贯审读全部关键事件，按行动前条件、执行、结果、信息来源、回应和下一步推演。缺少动机、关键行为或结果时先补正文；涉及主线、动机或结局取舍时提供具体方案并更新相关用户确认，常规衔接自主细化。
2. 镜头与关键帧画布：按实际播放顺序检查事件覆盖、省略两端及所有事件/场景/分段边界。先补缺失镜头或关键图，再生成组内中间帧；增加同一姿势的图片数量不能补上缺失的叙事环节。
3. 动作及合成：检查全部采用帧、接触点和相邻切换，再检查剪辑后的动作与反应先后。合格动作在错误剪辑位置也可能破坏因果，须对照实际时间轴。
4. 成片：按观众能获得的信息连续看完整场、整段及段间衔接；能否说清人物为何开始、实际做了什么、哪里省略、结果如何、谁因何回应以及下一步为何成立。声音和字幕可提供必要信息，但不能用解释字幕或旁白掩盖本应演出的关键事件；听音与播放能力不足时如实保留待核验项。
5. 每个缺口记录所属事件/镜头/时间、前后状态、断在哪一环、修复方式和复查范围。缺事件先修剧本，缺连接补镜头，缺动作补完整姿势，剪错则修时间轴；修复后复查从前因到结果/回应/下一步的完整范围及下游依赖。尚有无法解释的关键跳跃时不标记连续性通过。
