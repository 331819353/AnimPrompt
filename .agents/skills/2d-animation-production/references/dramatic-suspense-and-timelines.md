# 戏剧化悬疑改编与多时间线

创作或改编采用至少两条有实际作用的时间线，写出完整人物对白、场景、行动和结局。仅制作已确认剧本时沿用其结构；要求改编时先交付修订稿，按既有节点确认。

## 先确定真相，再安排观众怎样得知

1. 明确人物目标、代价、行动时机和互相冲突的利益，建立完整真实因果与谜底，再编排非线性正文。
2. 每场写明时空、活动、冲突、自然对白、关键接触、结果与反应。场景提供行动、取证或遮挡所需的具体条件，不用“气氛紧张”“双方争执”代替表演。
3. 转折来自前文事实和人物选择；误会有可信信息差，明显可行的解决办法须被尝试或有成立的限制。悬疑不默认采用犯罪、恐怖或悲剧题材。

## 分清三种时间与信息范围

| 维度 | 用途 |
| --- | --- |
| 故事发生时间 | 事件真实时刻或相对先后，用于检查因果、道具归属、相遇及信息传递 |
| 叙事呈现顺序 | 观众先看什么、何时揭示，允许倒叙、插叙和交叉剪辑 |
| 成片播放时间 | 各段从零开始的声画、字幕和触发位置，依据实际音频及工程核定 |

在连续性/镜头表中记录时间线、稳定事件标识、真实先后、呈现顺序、所属段/场景，制作时补镜头和段内时间。人物知识按故事时刻推演，观众知识按播放顺序推进，旁白按叙述身份限定信息；观众知道不等于人物知道。

同一事件重现沿用事件标识，另记呈现位置/视角。回放可补原先未见信息，已确立的客观动作、台词和道具状态保持一致；同一交接、损失或凭证不重复累计。历史镜头使用对应服装、年龄、环境及道具版本，返回原线接续其状态。

## 时间线之间怎样切换

每条线有目标、阻碍和局部结果，切换用于回答疑问、补因果、形成对照或带回新风险。并行事件的时长、通讯和先后须相容，画面相似不能作为同时发生的依据。

正文标明时间线、地点、日夜或相对时刻。首次进入及容易误认的切换处，用环境、服装/道具版本、旁白或时间文字提供足够定位；不只靠轻微调色，也不逐次重复长字幕。回忆、事实、推测与假想画面区分性质。

时间线数量与上/下或上/中/下分别决定。每段有问题、进展和局部回报；有意暂缓的答案或动作记录停点与后段恢复，台词不被截断。跨段动作保存采用帧序，完整变化仍满足至少六张有效图片；片段不冒充完整动作，重复前情不重复累计结果。

## 交叉推进与结尾汇合

各线独立推进人物处境，并相互解释。可用当下追寻结果、过去展示关键选择、更早经历解释关系；第三条线须有新增作用。

在现有记录中标出“本线疑问 → 另一线的部分解释 → 行动或判断如何改变 → 最终兑现位置”。交叉依据事件、关系、道具、对白含义或后果组织，声画呼应辅助过渡，不按固定秒数轮流切线，也不把各线分别讲完再并列总结。

过程中兑现局部问题，由新语境改变观众对旧动作、沉默或误会的理解。生活细节也可承担性格和情绪，不强制全部成为线索；观众猜到部分事实后，人物怎样承受后果、修正误解和选择仍有看点，不临时改谜底。

主剧本确定汇合点，分段稿落实到末段实际场景：

| 汇合内容 | 验收要求 |
| --- | --- |
| 因果 | 能复原关键事件先后，理解各线如何形成同一结果、说法或误会 |
| 线索 | 已见证据和细节互相印证，支持答案，不靠结尾无铺垫的新事实 |
| 情感 | 动机得到理解，人物回应后果和代价，作出当前选择 |
| 首尾呼应 | 重现已有动作、场景、道具或话语，让早先事实获得更完整的含义 |

汇合指因果、信息与情感相互解释；跨时空并置分别引用各自镜头基准，不混用物理状态。人物发现、核验和行动先支持揭晓，旁白/对白再自然串清剩余因果，可补关键历史视角；不以全新长独白或重放全剧代替汇合。留出人物回应和情绪落点，讲明核心事实，未来选择可保留余韵。

## 线索的铺垫、误导、核验与回收

与连续性记录合并：

| 记录 | 内容 |
| --- | --- |
| 线索与真义 | 具体道具、动作、声音、对白或规则，支持什么解释；事实与人物说法分开 |
| 铺垫 | 所属线、事件和播放位置，谁能接触，对应实际镜头/音频/文字 |
| 初次理解 | 误读为何合理，暂缺什么信息；客观旁白不撒谎，不篡改已见事实 |
| 核验 | 后续证据或行为怎样改变解释，作出判断的人如何获得信息 |
| 回收 | 解释位置，怎样改变选择、关系、任务或代价，回应哪个悬念 |
| 状态 | 计划、已呈现、待核验、已回收或有意保留的次要问题，关联采用版本 |

关键答案所依赖的线索在揭晓前可感知，首次可不显眼，事后须能复核。重要文字用核对文本层，声音线索在混音中可辨；仅写在制作表中不算呈现。误导也有归宿，回收通过证据及后果成立，不只靠人物宣布答案。

按揭示计划给出信息，可先展示结果再追问原因。角色说谎、不可靠回忆或反讽须有视角依据并可后续核验，不能当作已确立的客观事实；旁白不超出当前计划泄露待推理答案。

## 旁白、对白、动作和场景共同承担一场戏

旁白提供背景和衔接，对白体现目的、试探、隐瞒和回应，动作承担取证、接触、受阻与结果，场景提供空间及线索。同一信息有意复现时须增加作用，无新意义的同步复述删减。

[声音编排](voice-and-audio.md#旁白身份与声音编排) 与实际播放顺序对应；发声相关完整帧在选用真实配音后生成，无声组可并行。声音或剪辑改变时复查表演、字幕、揭示顺序和线索可感知性。

## 写作及制作自查

1. 按故事时间推演真实因果，再按播放顺序检查信息。逐场核对人物知识、历史状态、行动结果及对白/旁白，复查跨线、返回原线和跨段。
2. 核对各线作用、交叉点和末段汇合；能分别讲清“实际发生了什么”和“观众为何此时才理解”。删掉某线若无损于事件和情感，重写其作用或合并。
3. 逐条检查线索实际铺垫、误导依据、核验来源、回收及后果，修复关键矛盾和未兑现的主线问题。区分剧本计划与实际声画证据。
4. 按缺口修正文、揭示顺序、历史版本、镜头或动作，复查下游知识、铺垫和回收。审稿向用户展示真实因果与谜底，发布文案按观众应知范围保留悬念。
