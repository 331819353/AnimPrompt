# 简笔水彩画形式

仅在 `visual_style` 为 `simple-watercolor` 时读取。以简洁手绘线稿、轻薄淡彩、自然晕染和适量留白表现人物与场景，细节足以辨认角色、看懂动作和剧情即可。完整动作图片及连续性见 [视觉与表演](visuals-and-performance.md)，运行工具、程序合成及检查方式见 [制作执行与能力边界](production-execution.md)。

## 制作方式与能力边界

Agent 组织美术设定、场景和表演，按 [生图路由](canvas-and-image-routing.md) 优先即梦、不可用时用 Image Gen 制作图片并统一入画布。用户选择 [连续动画或翻页动画](animation-routes.md)，画风不代替路线选择；本地工程统一剪辑/换帧及导出。线稿、淡彩和身份以实际图片及动态样片核验，提示词不保证一致性。

## 构图与情境表演

1. 先设计可理解的完整故事场景，明确空间、光源、人物活动区域及前后遮挡。背景用简洁线条和淡彩大形体交代建筑、家具与关键道具，保留可供移动、接触和操作的空间；留白不能抹掉动作所需的门、桌面、座椅或支撑关系。
2. 人物轮廓、脸型、发型、服装和主色清楚可辨，表情与身体姿势能表达意图。造型可以简化，年龄、体型和身份仍有差异；省略装饰细节不能造成手脚缺失、关节不连、握持不明或表情无法辨认。
3. 站位、视线和镜头围绕人物关系与动作目的安排，用拿取、递交、走动、落座、操作和反应推进剧情。景别随叙事需要变化，关键因果在镜头中可理解，简笔风格同样遵守 [动作与场景交互](visuals-and-performance.md#动作与场景交互)。
4. 互动关键图/姿势包含完整人物及关联道具，保持重心、接触和遮挡，不拆嘴、头或肢体拼接。连续动画用完整镜头关键图控制运动；翻页动画复用固定背景，同组完整图片按统一画布与锚点换帧。

## 水彩美术与角色一致性

1. 采用简洁、自然的手绘线条和少量透明水彩铺色，保留轻微笔触、不规则晕染边缘及纸感。配色协调、主体与背景容易区分，以少量明暗和冷暖变化交代体积与情绪；不默认追求精致插画、密集纹理、厚重层涂或复杂光影。
2. 人物、道具、场景和封面共用线条粗细、用色、简化程度与纸感。建立标准人物图和场景基准，固定同组的五官、发型、身体比例、服装款式/颜色、光照及机位；不同景别仍引用同一身份设定。不同故事时刻按已确认的年龄/服装/场景版本制作，身份可辨，同组逐帧保持该版本，不将历史变化当作随机漂移。
3. 同一固定镜头中的纸纹、静态晕染、线稿和色块位置保持稳定，不随帧随机重画以制造手绘感。运动部分的笔触和着色随形体合理移动，无关区域复用；检查纹理游动、线条闪烁、色块跳变及明暗呼吸，不能将这些错误算作有效动作变化。
4. 工程默认在 1920×1080 组织画面和布局，可使用有足够清晰度的更高分辨率源图。记录生成实际尺寸与工程尺寸，按整组相同规则整理；缩放采用保留线稿、柔和晕染和透明通道的高质量采样，检查清晰度、色边与换帧稳定性，不沿用像素网格、640×360 逻辑画布或最近邻三倍放大。
5. 独立完整角色、道具和特效使用真实透明背景，保留柔和笔触及半透明边缘；纸张底色与底纹固定在场景层，不能让每张角色图带着一块白纸遮住背景。检查实际合成后的白边、暗边、脏色及叠色，保持同组尺寸、比例、锚点和统一合成方式，不逐帧紧裁、居中或独立缩放。
6. 简笔水彩从统一参考和实际绘画内容开始创作，不给旧像素图或照片加水彩滤镜就作为风格转换完成。根据时代、地点与身份保留剧情必需的服装和道具特征；在最终尺寸及手机尺寸检查表情、动作、接触点与关键信息。
7. 标题、字幕、气泡、计数器及说明文字预留构图位置，使用核对后的文字层在最终分辨率独立排版。封面按 [封面与发布](covers-and-publishing.md) 分别组织三种比例，沿用正文的线稿、淡彩、纸感和角色设定。

## 首尾帧、中间帧与校验

主剧本、分段稿、清单及路线确定后，按 [画布流程](canvas-and-image-routing.md#逐级确认与首尾帧先行) 建立标准参考与关键图，补齐剧情覆盖并确认画布；核对关系、起止、空间、用色、纸感与手机可读性。

连续动画按 [连续动画](animation-routes.md#连续动画) 以默认三状态及必要接触图生成相邻片段，检查实际运动与连接，不另补六图。翻页动画按 [上一帧微调](visuals-and-performance.md#标准参考图与上一帧微调) 顺序编辑，保持非动作区域，完整序列遵守 [至少六张](visuals-and-performance.md#变化单元与至少六张有效图片)，复杂变化继续补帧；整图直接替换，不用淡化掩盖缺步。

样片除身份、肢体、道具接触、状态和节奏，还检查纸纹、线稿、柔边与淡彩稳定。连续动画检查全部采用片段运动及每处连接，翻页动画检查全部采用图及相邻切换，具备条件时正常速度和慢速播放。修复后复查依赖，每片用户确认后再生成下一片；文字在最终分辨率排版，统一 1080p 导出。

组织生图提示时说明用途、主体、情境、构图、光源与保持条件，使用“简笔水彩画、简洁手绘线稿、轻薄透明淡彩、自然晕染、适量留白、轻微纸感、人物与场景简洁且动作清楚”。连续动画编辑镜头关键状态，翻页动画以上一合格帧推进微小动作；均核对静态笔触、色块与纸纹，输出完整图片。
