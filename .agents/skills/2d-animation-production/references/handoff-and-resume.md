# 阶段衔接与续作

本文件管理作品的范围、采用版本、阶段交接和恢复。具体创作方法见 [剧本创作](scriptwriting.md)、[视觉与表演](visuals-and-performance.md)、[配音与音频](voice-and-audio.md)、[动画与交付](animation-and-delivery.md) 及 [封面与发布](covers-and-publishing.md)。按本次任务读取有关部分。

## 开始项目

1. 确定本次模式、范围和作品目录，检查剧本、素材、工程及 `project_state.json`。多个作品分别保存，成果不写入 Skill 源码目录。
2. 优先采用用户指定版本；多个候选无法判定时只询问采用版本。沿用可靠编号、偏好与已确认内容。
3. 创作/改编按 [剧本创作](scriptwriting.md) 与 [多线悬疑](dramatic-suspense-and-timelines.md) 处理；仅制作已有剧本时检查制作输入，不自动改写。改编保留事实和用户指定核心。
4. 核对主剧本、分段稿、清单及视觉节点的实际确认范围。指定采用剧本可视为该版本正文确认，明确认可分段时才覆盖分段；主线疑问或实质改写更新对应确认。

## 用户沟通与确认

| 节点 | 审阅成果 | 确认后推进 |
| --- | --- | --- |
| 方向（有未决问题时） | 主题/事实边界、人物目标、冲突、结尾及代表性对白 | 编写完整主剧本 |
| 完整主剧本 | 完整场景、行动、对白、旁白与结局；真实事件先后、谜底、跨线交叉点和最终汇合 | 编写分段稿，不生成图片 |
| 分段剧本 | 上/下或上/中/下完整正文，各段约 3–5 分钟、看点/回报、悬念、跨线衔接及回收 | 整理录音稿和待确认清单 |
| 人物/场景/关键道具清单 | 稳定标识、人物/空间/道具及历史版本、所属段/场景、关键变化起止和图片需求；旁白声音身份 | 检查生图条件，生成标准参考和关键首尾帧 |
| 首尾帧画布 | 实际标准参考、首尾及必要关键图；补齐的剧情/线索覆盖，动作起止和状态 | 规划中间姿势，逐帧完成样片所需动作 |
| 代表性样片 | 约十至十五秒实际动画，含对白/旁白、情绪、场景交互、结果和字幕；必要试音/跨线边界预览 | 扩展其余动作和分段成片 |

先完成实际成果及 [阶段自查](#阶段自查与放行)，修复明显问题后提供文件/预览和具体确认项。纯画外旁白只需 [发声身份](voice-and-audio.md#旁白身份与声音编排)，不生成人物图；审稿向用户展示真实因果与谜底，发布材料保留观众悬念。

确认记录成果路径、版本、范围、决定与依据；一次明确覆盖多个已有成果时分别登记。沿用已有决定，技术修复自主完成，影响主线、动机、结尾或表现基准的改动更新相关确认。

当前节点待确认时暂停其依赖工作，继续独立任务。明确授权全权创作或跳过节点时记录范围；未回复、已生成、自查通过或笼统要求成片均不等于内容确认。

## 阶段自查与放行

采用、审阅和交接前检查实际成果；跳过创作审阅不免除质量检查。覆盖本次全部采用文本、图片、动作及叙事段，技术、视觉、听音和连续播放分别记录，证据要求见 [制作执行](production-execution.md#检查依据与适用边界)。

| 阶段 | 检查重点 |
| --- | --- |
| 方向 | 事实/类比边界、人物目标、冲突与结尾，是否有动机缺口或未解释的明显解决办法 |
| 主剧本 | 全文因果、规则/数量/时间、自然对白、旁白、具体行为、转折和结局；按 [剧本自查](scriptwriting.md#交付前自行审读并修改) 复核 |
| 分段稿 | 对照主剧本检查完整覆盖、各段约 3–5 分钟、戏剧性、局部回报、悬念及后段接续/兑现 |
| 清单 | 角色、场景、道具、历史版本及所属段/场景覆盖，旁白声音身份、关键变化起止与图片需求 |
| 首尾帧画布 | 标准参考、起止可达性、身份/机位/光照/状态、本地版本与节点对应，补齐本阶段剧情和线索关键图；不将两张首尾当完整动作 |
| 录音稿与声音 | 全部对白/旁白的顺序、覆盖、发声者、正文/生成文本、选用音色与版本；漏句、重复、读音、句尾和标签，见 [声音核验](voice-and-audio.md#音频定稿版本与成片时间轴) |
| 完整动作及中间帧 | 每个变化至少六张有效不同且实际采用的完整图；标准参考/上一合格帧/目标尾帧、身份、画布/锚点、肢体、头身、支撑、道具朝向及全部相邻切换 |
| 动作段与样片 | 实际合成中的场景交互、接触/结果、状态、重影/滑步/穿透、声源/嘴形、停顿、字幕/音效定时，复查末端与循环衔接 |
| 分段动画与整体故事 | 全部段的内容、真实声画时长、活动/节奏、镜头/场景/段界；历史状态、跨线定位、人物知识、线索回收及末段因果/情感汇合。有播放能力时完整观看和听音 |
| 封面与文案 | 逐段三比例实际封面及小尺寸预览；文字、构图、身份/画风、段序与本段看点，保留后段反转，见 [封面规范](covers-and-publishing.md) |
| 导出与交付 | 全部要求的 MP4、同名 SRT、封面和文案；规格、完整解码、内容覆盖、字幕零点/越界、声画起止及当前选用版本，见 [交付规范](animation-and-delivery.md) |

[连续性](story-continuity.md) 分事件因果、镜头边界和动作帧检查；[多线悬疑](dramatic-suspense-and-timelines.md) 先按真实时间核对因果，再按播放顺序核对信息。有意隐藏按揭示位置检查和兑现，不因当前未揭晓就补图泄底；计划、实际声画和播放证据分开。

旁白核对说明/推进作用、声音及画面对应，避免抢掉对白/反应、驱动无关人物嘴形或把观众所知当成人物已知。关键事件以采用剧本及实际呈现为依据。

问题记录对象/版本/位置、方法/覆盖、修复、新版本和复查结果，复用统一检查入口。先修本阶段及下游真实依赖，再按下方状态定义放行；用户取舍与工具导致的待核验项分别说明。

## 作品进度记录

`project_state.json` 是作品的进度与依赖索引；台词、音频选用、视觉素材及时间轴各保留自己的详细记录，进度索引引用其路径和版本，避免重复维护一份正文或音频清单。

按实际工作填写以下信息，字段可以扩展，不为未执行工作伪造结果：

| 信息 | 保存内容 |
| --- | --- |
| 项目标识与范围 | 稳定的 `project_id`、作品名、当前模式、本次目标、明确偏好、输出目录、`visual_style` 及采用规范 |
| 采用剧本 | 完整主剧本的确认快照、分段剧本的当前采用路径/版本与相互来源关系；录音稿和制作以已确认的分段剧本为唯一正文依据，避免维护两份互相漂移的定稿；主题范围、事实截止日期、来源及结尾意图随剧本保存 |
| 分段计划与悬念衔接 | 话题生成采用上/下或上/中/下，已有指定剧本沿用确认结构；保存段名、顺序、内部标识与场景对应，各段目标时长、估时依据，制作后补实际时长；每段看点/回报、伏笔位置、观众期待与后段推进/兑现位置 |
| 分段交付索引 | 各段当前正式 MP4、同名 SRT、三种比例封面、发布文案的实际路径/版本/时长与检查状态；本段从零开始的时间轴入口及其与整体剧情的对应，各段完成情况与尚缺成果 |
| 用户确认与未决事项 | 各节点的成果路径/版本、用户决定及对话依据、适用范围、待回答的问题与影响；明确跳过节点时保存授权依据 |
| 阶段进度 | 当前阶段、检查状态、采用成果、所依赖的上游版本、未完成项 |
| 成果索引 | 相对作品目录的路径、成果编号、版本、依赖及实际检查记录位置 |
| 生图与画布索引 | 已确认的人物/场景/关键道具清单及关键变化表入口，作品画布身份/实际链接；各变化的首帧/尾帧、必要关键画面、缺失与补齐结果、中间帧计划和实际帧序；各图工具、节点/资源/本地文件对应、参考/上一帧/目标尾帧及采用/检查/同步状态，见 [生图路由与画布](canvas-and-image-routing.md) |
| 叙事连续性索引 | 指向与正文/镜头/动作表合并的 [连续性记录](story-continuity.md#关键事件要形成完整链条)，保留关键事件及状态、省略依据、信息来源/回应/下一步与实际呈现对应，以及边界检查、缺口和修复；内容随阶段细化，不预填尚未生成的镜头或通过结论 |
| 多时间线与线索索引 | 与连续性记录合并，保存真实事件先后、时间线与历史版本、叙事呈现顺序及段内成片时间；人物/旁白/观众知识、线索真实含义与铺垫/核验/回收位置、跨线提问/解释及最终汇合点、隐藏范围及兑现状态，按 [多线规范](dramatic-suspense-and-timelines.md) 随阶段关联实际成果 |
| 交接与恢复 | 角色/分场/叙事段对应记录、音频和素材清单、工程与时间轴入口、下一步、工具或素材缺口 |
| 变更记录 | 修改缘由、受影响范围、仍可复用成果、需更新或复查的部分、更新时间 |
| 实际运行与检查 | 当前工具/运行时、字体、图片与编码依赖、工程运行入口；各阶段自查记录入口、对象/版本/位置、方法与覆盖、发现问题/修复版本/复查结果、仍需处理或待核验项；技术/画面/转写/听音/连续播放分别记录 |

阶段可以使用 `script`（完整主剧本）、`segmented_script`、`asset_inventory`、`keyframes`、`manuscript`、`visuals`（完整动作图片）、`voice`、`timeline`、`animation`、`mix_subtitles`、`covers_copy`、`export_qa`。阶段状态统一为 `not_started`、`in_progress`、`passed`、`needs_recheck` 或 `blocked`；阶段下记录实际通过的叙事段或素材。`keyframes` 通过不代表中间帧或连续动作已完成。

- `passed`：该阶段当前采用成果已满足本次目标的交接条件，且阶段自查与问题复查已完成、检查依据仍有效；区分文件生成、技术核验和感知检查，有影响交接的已知错误或必需检查尚未执行时不能标记为已通过。
- `needs_recheck`：依赖的内容或配置发生变化，需要更新或重新核验；记录具体范围，无须否定整个阶段的所有素材。
- `blocked`：该阶段缺少必要输入、工具或素材；记录恢复条件，其他独立阶段仍可推进。
- “本次请求完成”与“整片完成”分别记录。只写剧本完成后，动画阶段仍是尚未执行，不能把它们标为通过。

用户确认单独用 `user_review` 记录，核心节点为 `script`、`segmented_script`、`asset_inventory`、`keyframes`、`sample`，需要方向讨论时另记 `direction`；状态为 `pending`、`confirmed`、`waived` 或 `needs_reconfirm`。记录关联版本、范围、决定与依据；`waived` 仅用于明确授权跳过的范围。旧记录的 `script: confirmed` 须核对实际覆盖，不能自动放行清单或关键帧。技术与内容自检保存在阶段检查中，等待确认时记录暂停的依赖和下一步，不误报为工具故障或整片完成。

首次仅写剧本时，记录项目范围、剧本版本与阶段、有关用户确认与未决事项、必要角色与分场标识及下一步即可。进入动画阶段再补充对应清单和工程信息，不预填虚假的音色、素材路径或调用日志。工程已有格式足以表达这些信息时可复用，在索引中指向它们。

## 稳定编号与版本

角色、分场、叙事段、镜头、台词段及复用素材使用稳定标识，建立必要的对应关系。作品内首次分配后不因插入、删除或调整顺序而给所有旧成果重新编号；播放顺序单独记录。新增内容使用未占用标识，删除内容标记停用，旧标识不分配给另一内容。显示名称可以改，标识继续关联原对象。

新作品的叙事段按播放顺序使用 `P01`、`P02`，采用三段时再加 `P03`，显示为上/下或上/中/下；例如台词 `P01_D001` 归属上段。工程编号只用于引用与追溯，不呈现为章、节标题。已有工程保留可靠编号，旧 `CH` 标识与新段名登记对应关系，不为改显示结构批量重编号；段界或剧情实际改变时更新真实依赖。

已有完整编号时沿用并核对唯一性。只有在动画制作需要时才建立镜头、素材等标识；单纯写剧本不扩张成整个制作工程。台词段编号、生成文本与音频版本的细则见 [配音与音频](voice-and-audio.md)。

“采用版本”表示已满足相应自检与用户确认条件、用于下游的版本；待审阅成果单独标明，不因自检通过就登记为已确认。生成新版本保留原稿、原始媒体和必要工程副本；用清楚的文件名或工程版本机制区分候选与采用结果。参考文件是制作规范，作品的剧本、记录与工程才是实际成果。

## 阶段交接条件

| 交接 | 下一阶段需要什么 | 校验与完成边界 |
| --- | --- | --- |
| 主题 → 完整主剧本 | 已明确的核心问题、范围、故事方向与必要事实依据 | 交付完整故事正文，动机、因果、自然对白、关键行为、反转与结局经自查后交用户确认，不用方向大纲代替 |
| 完整主剧本 → 分段剧本 | 已确认的主剧本路径/版本、剧情与结局、角色关系及来源 | 主剧本确认后再编写上/下或上/中/下完整分段稿，逐段约 3–5 分钟、看点/回报/悬念与承接可核对，分段稿另经用户确认 |
| 分段剧本 → 清单及录音稿 | 已确认分段正文、人物/分场/关键行为/道具状态、对白与必要旁白、来源及伏笔兑现记录 | 提取人物、场景和关键道具清单与变化起止计划，自查后交用户确认；录音稿可并行整理，但清单确认前不生成图片 |
| 清单 → 标准参考及关键首尾帧 | 已确认清单与分段剧本、视觉形式、必要参考及当前生图条件 | 即梦优先、Image Gen 备用，建立标准参考后生成各变化首尾及必要关键画面，逐张检查并入画布；首尾生成阶段不提前投产中间帧 |
| 首尾帧画布 → 中间帧 | 对应分段正文的首尾与关键画面、缺口及补齐记录、用户对当前画布的确认、必要动作路径 | 缺失关键画面先补齐，画布确认后才逐帧补间；先完成代表性样片动作，核对尾帧衔接与有效数量，样片确认后扩展其余组 |
| 录音稿 → 配音及表演定时 | 完整录音稿、稳定台词段编号、已确认人物清单、表演说明、生成文本与生成清单 | 不漏句、不重复、标签与说明分开；输入齐备后按 Fish 音频流程生成样片声音，图像工作仍遵守清单与首尾帧确认，最终嘴形/动作/字幕定时由真实声音核定 |
| 图片 → 正式合成 | 已确认首尾与标准参考、补齐的关键画面、每个完整变化至少六张有效不同图片、实际帧序与上一合格帧/目标尾帧、统一画布/比例/锚点及遮挡、本地采用版本与画布对应 | 中间帧逐张检查，首尾/关键姿势间过渡及末端衔接连续；数量、变化内容、实际采用与修复依赖均通过复查，已查看合成预览；画布同步单独标明，水彩另查笔触、纸纹、淡彩及透明边缘的跨帧稳定，不能仅凭关键帧确认或达到六张放行 |
| 配音 → 时间轴 | 已生成并完成可执行核验的选用声音、`audio_manifest.json`、所属叙事段、工程文件及处理后时长 | 唯一选用与分片顺序明确，真实时长、本段正文覆盖及检查状态可核对；建立各段从零开始的视频时间轴并保留剧情对应，未试听内容继续标记待核验。可先制作可用段，整套交付前须覆盖全部要求的段 |
| 时间轴 → 样片及叙事段动画 | 采用声音与图片、统一时间轴版本、关键动作/状态/信息/嘴形/字幕/声层的对应位置 | 先制作有代表性的约十至十五秒样片并修复，提交用户确认后再批量展开叙事段；已确认且通过检查的基准可复用，整片完成仍须覆盖全部叙事段 |
| 分段成片 → 配套复核、整套交付 | 与剧本一致的上/下或上/中/下各段 MP4、同名 SRT、本段三比例封面与文案、可复用工程、实际检查记录 | 逐段核对内容、约 3–5 分钟目标、本段字幕定时、配套准确性与规格/解码/画面/播放，再检查段间承接与整体收束；全部要求的段及配套成果完成后才标记整套完成，缺失部分继续修复，未核验项明确交付 |

制作阶段在完成成果、选择新版本、发生重要变更或暂停工作时更新索引。记录完成后明确下一个可执行动作与所需文件，使新聊天能从作品目录恢复。

图片到合成的条件针对正式采用，允许先运行技术合成预览发现定位、遮挡和衔接问题，不要求在获准检查预览前就已有预览结果。发声相关完整帧依赖选用真实配音，无声组和独立工程检查可并行；所有正式采用图片仍须完成自身检查。

## 变更传播与复查

先定位修改内容的真实依赖，再更新涉及的成果并标记复查范围。复用不受影响且仍通过检查的部分；必要的后续连续性和定时复查不能省略。

| 变更 | 需要检查的依赖 |
| --- | --- |
| 台词、旁白或剧情顺序 | 录音稿正文/生成文本、相关配音、镜头和表演、状态/信息、字幕、叙事段及全片时间映射 |
| 音色、标签、读音处理、配音选用或声音编辑 | 音频版本/选用清单、实际时长、嘴形/动作/停顿、字幕、混音及后续偏移 |
| 角色造型、场景结构、机位、道具状态或动作结果 | 有关图片/姿势、视线与道具可读面/可见面、遮挡/接触、连续性记录、后续状态与数据展示、相关封面 |
| 标准人物图、镜头初始帧或连续序列中的某帧 | 引用该参考的动作组，以及依赖修改帧生成的后续帧；重新核对固定属性、动作进度、帧来源/版本、相邻切换及完整序列预览，必要时重生成受影响帧 |
| 主剧本、分段、清单或已确认首尾关键帧 | 按实际改动更新相关确认范围，检查分段正文与清单覆盖、画布缺口/补齐、动作起止/中间帧规划及已生成依赖；尾帧改变时复查整组过渡和末端衔接，不默认全部节点继续已确认 |
| 生图工具切换、画布节点采用版本或本地对应变更 | 切换后的首帧及连续动作的身份/固定属性/相邻过渡，画布来源引用、受影响下游帧、清单中的采用与同步状态，以及合成实际读取的本地版本 |
| 视觉形式切换 | 新形式的角色/场景参考、有关完整动作图片、排版、采样和输出配置、封面及检查记录；剧情和配音内容未变时复用已核验声音，重新核对受影响的表演与时间轴 |
| 事件结果、过程省略、交接成败、人物获知信息或回应/下一步 | 连续性记录、相关正文及确认范围、两端镜头/关键图、道具归属和任务进度、下游人物的知识与选择、画布覆盖及实际剪辑；复查完整因果链及跨场/跨段边界，不只检查被改的一张图 |
| 真实事件先后、时间线切换、隐藏范围或线索揭示/回收 | 主剧本与分段采用范围、人物/旁白/观众知识、历史素材版本、对白/旁白及声桥、铺垫和核验镜头、段尾悬念与后段恢复、最终播放顺序；同一事件重现不重复累计结果 |
| 结尾意图或尾声情节 | 相关剧本、伏笔、录音稿/配音、尾声画面与定时、完整结尾检查、封面及发布文案 |
| 工程画布、姿势组基准、角色比例/锚点、纸纹/淡彩基准、采样/缩放比例或工程定位 | 同组完整动作图片的规格与对齐、有关图层、镜头、信息文字、封面落版、合成及导出配置 |
| 镜头时长、留白、段落顺序或无声动作 | 时间轴、状态变化/信息/音效、叙事段偏移、嘴形、字幕、混音及导出 |
| 封面创意或发布标题 | 三种比例的识别、所选风格、故事看点和实际成片对应；若仅调整封面，不自动重做音频 |
| 事实依据、数量定义或类比关系 | 剧本中相应表达、画面信息及状态、适用的录音稿/配音/字幕与发布文案 |

时间轴变化从受影响位置重新核对后续偏移。时间增加不等于故事中发生了新动作；数据不因重复播放或镜头调整重复累计。仅改显示名称时更新引用；文本或事实变化则更新真正使用它的内容。具体声音定时见 [配音与音频](voice-and-audio.md)，状态推理见 [视觉与表演](visuals-and-performance.md)。

## 恢复与继续制作

1. 读取 `project_state.json` 和最新请求，检查采用剧本、关键清单、工程与文件是否实际存在，核对版本、依赖、已有检查与用户确认依据，继续处理未决问题。索引与实际文件不一致时，以核对结果修正记录，不把文件存在等同于已经通过检查或用户确认。
   跨聊天或环境恢复时按 [制作执行与能力边界](production-execution.md#按阶段检查运行依赖) 重新确认工具和工程入口。认证、返回 URL、运行时路径或工具参数变化不能由旧记录替代核对；保留可用的本地文件和通过检查的成果。
2. 项目没有进度索引时，从实际剧本、音频清单、素材和工程重建最小索引。保留可靠编号、音色和素材；缺失的检查标记待核验，不宣称旧成果已经播放或检查。
   恢复镜头或补帧时同时读取所属时间线、事件真实先后、播放位置及前后衔接记录，核对该故事时刻的任务进度、道具持有者、人物/观众信息和省略/隐藏依据；回到原动作组使用该组上一合格帧。旧记录只有动作首尾或含义不明的“剧情时间”时补足三种时间与边界检查，不能默认跨线/跨场已通过。
3. 将用户新要求合并到原目标并限定实际范围。继续时依次核对主剧本、分段稿、清单、首尾帧画布与样片的确认及版本，从首个未满足依赖的节点接续；已覆盖的决定沿用，不因旧的笼统 `script` 或 `visuals` 状态跳过节点。沿用 `visual_style`，明确切换形式时更新有关依赖、确认与复查，不混用旧形式素材及采样配置。旧 `japanese-pixel` 工程切换到 `simple-watercolor` 时，重建水彩参考与受影响图片，更新采样、透明合成和封面，复查关键帧及样片；仅修改标识或添加滤镜不能视为迁移完成。
4. 遇到未确定结果的媒体调用，先查询已有响应、任务和文件，再决定是否重试。修复缺失或失败部分，保留通过检查的结果，不把恢复等同于全部重生成。
   沿用当前“Fish 仅音频”的分工。旧记录中的 Fish 图片/视频或图生视频测试标记为停止、仅供历史核对，不因订阅或余额变化自动续跑；图片仍按即梦优先、Image Gen 备用执行，视频使用采用图片的合成工程。保留原始响应，不将曾返回模型目录或报价失败改写成生成成功。
   恢复图片工作时按 [生图与画布恢复](canvas-and-image-routing.md#本地同步自查与恢复) 核对原画布、任务、节点、本地文件及已确认清单/首尾，补传待同步图片并检查关键画面缺口，保留工具与切换依据。首尾画布已确认后，核对同组实际尺寸、标准参考、比例/锚点、上一合格帧与目标尾帧及检查状态，再接续中间帧微调；缺失检查先补核验。旧工程的局部身体部件改为完整姿势并更新换帧配置，不将旧部件标为符合规范。
5. 依赖临时不可用时记录阶段缺口与恢复条件，继续可执行的独立工作。恢复后核验实际结果，再进入相应下游阶段；没有真实声音时可继续静态图片及镜头构思，最终嘴形与字幕定时留待声音核定。
6. 更新记录并按播放顺序交付本次各段实际成果和剩余事项。要求完整动画时持续完成全部要求的段及配套；明确暂停、只做某段或一个阶段时保存进度，在该边界停止。已导出的旧版本可保留，各段最终交付清楚指向本段唯一当前正式版本；一段完成不等于整套完成。
