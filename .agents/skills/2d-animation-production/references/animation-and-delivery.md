# 动画与交付

建立成片时间轴、制作样片或全片、字幕、导出及最终检查时读取。只写剧本的交付见 [剧本创作](scriptwriting.md)；本文件的完整成片清单适用于动画制作目标，局部修改按本次范围交付有关成果。

采用版本及阶段恢复见 [阶段衔接与续作](handoff-and-resume.md)。角色素材与表演见 [视觉与表演](visuals-and-performance.md)，声音的选用和工程时间映射见 [配音与音频](voice-and-audio.md)，封面与文案见 [封面与发布](covers-and-publishing.md)。

内容：1080p 输出与字幕；制作流程与质量检查；阶段与最终交付。

优先由 Agent 编写和运行可复用的本地合成工程，使用完整图片、统一时间轴及采用音轨生成实际动画。运行依赖、流式或分章节渲染、清单与配置保存方法见 [制作执行与能力边界](production-execution.md#合成工程与共同时间轴)。只在当前环境确实能控制既有动画软件时接续其工程，不把人工软件操作设为默认步骤。

## 1080p 输出与字幕

1. 只输出一个正式完整成片：横屏 16:9，1920×1080，24 fps，MP4 容器，H.264 视频与 AAC 音频。
2. 使用合成软件或本地脚本，按作品选中的形式完成画面。日系唯美像素使用 [像素形式](style-japanese-pixel.md) 的逻辑画布和固定整数倍率，以最近邻方式一次放大至输出尺寸；讽刺手绘卡通按 [卡通形式](style-satirical-cartoon.md) 使用最终尺寸及适合线条的采样。再添加最终分辨率的文字层，导入定稿配音，完成字幕渲染、音画合成与编码；保存视觉形式、画布、采样、实际倍率、工具及导出配置。分镜预览和样片归入过程素材。
3. 字幕准确同步，每屏尽量不超过两行，固定在画面安全区域，不遮挡表情、关键动作和重要道具。
4. 字幕文字取自朗读正文，依据成片时间轴上的实际配音及可确认的语义短段起止定时，核对完整对白、旁白和正文中的拟声词；支持听音时进一步复查，不根据文本均分伪造逐字定时。标签、导演说明及用于纠正读音的替代拼写不进入字幕；纯笑声、叹气等不直接显示为控制标签。自动识别结果仅辅助校验，MP4 与 SRT 共用最终文本和定时。
5. 画面和最终混音覆盖同一成片时间轴，包括配音、留白、无声动作及片头片尾，章节衔接自然，配音完整且不被拉伸或截断。导出后读取视频与音频规格，完整解码核对文件、长度和覆盖；查看各镜头及关键变化的实际画面，环境支持时连续播放检查声音、同步、字幕与结尾。按实际方式记录检查，不把成功编码或抽帧称为完整观看。

## 制作流程与质量检查

按以下步骤自主完成制作，复用合适的既有素材与已通过检查的成果。录音稿交付后，图片制作和配音生成可以并行；先以小范围成果验证生成与合成链路，再扩展全部章节。运行依赖和检查依据按 [制作执行与能力边界](production-execution.md) 执行。

1. 理解剧本，识别叙事、表演和信息表达的重点与难点。划分章节并整理正文，按 [配音与音频](voice-and-audio.md) 交付录音稿.md 和生成清单；根据各段情境构思镜头与表演。
2. 检查当前媒体工具、图片处理、字体和编码依赖。读取选中的形式规范，使用 Image Gen 创作静态小样和代表性完整动作小组，建立角色、场景和美术基准，核对构图、轮廓、色彩、光影和细节密度。
3. 按 [完整动作帧与对齐校验](visuals-and-performance.md#完整动作帧与对齐校验) 检查每个动作的完整图片、同组画布/比例/锚点及换帧稳定性，同时核对角色和场景一致性，整理图片及复用关系。音频尚未取得时可完成图片、动作结构和镜头规划，具体嘴形姿势选择、停留时长与字幕定时留待真实声音核定，不凭预计时长宣称有声动画完成。
4. 按 [配音与音频](voice-and-audio.md) 查询角色音色，通过实际接口试配代表性台词和关键情绪段。固定选用音色、生成文本及可用配置，按当前环境能力记录技术、转写及听音结果；工具异常保留实际恢复条件。
5. 修复不合格结果，确定样片选用版本并登记 audio_manifest.json，完成必要工程整理，记录实际处理后的时长与位置。未执行的听音检查不登记通过，不用预估时长替代真实声音。
6. 将选用音频、镜头与表演映射到成片时间轴，关联文本、音频和素材版本。记录剧情时刻、场景图层、完整姿势图片、姿势组、统一画布与锚点、持续帧数及整体位移，按同组定位规则整图替换；需要的状态变化、数据展示与音效引用对应记录，保持一致。
7. 运行本地合成工程，使用采用声音和完整图片制作约十至十五秒的 1080p 样片，验证真实的换帧、定位、遮挡、混音/字幕及编码链路。检查美感、表演、状态、信息可读性和同步，修复后复用合格基准、声音及工程，展开全部章节的图片、配音与动画，按需补充素材。
8. 持续校验叙事、场景、表演与版本，变更按 [阶段衔接与续作](handoff-and-resume.md#变更传播与复查) 更新关联内容，声音变更同时遵守 [配音与音频](voice-and-audio.md) 的版本与时间映射要求。修复后复查受影响镜头；完成声层、混音、字幕、三个比例的封面和发布文案。不能以图片、样片或计划替代完整动画。
9. 按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 导出正式成片与 SRT，执行实际规格、全片解码、镜头与字幕边界检查，并在手机尺寸复查。按环境能力执行连续观看与听音，记录方式和覆盖范围；全片须包含全部章节、配音与结尾，缺失或不合格内容继续修复，未能执行的检查明确保存。
10. 按 [阶段与最终交付](animation-and-delivery.md#阶段与最终交付) 核对交付清单，整理图片、定稿配音、音色与配置、调用记录、可复用工程及检查结果。

检查时执行“取得实际文件与检查视图/声音→检查→修复→复查”，记录问题、方法、覆盖范围、修复及结果。具体证据要求见 [制作执行与能力边界](production-execution.md#检查依据与适用边界)，检查重点为：

- 流程与工具：录音稿完整，制作按规定顺序推进，配音通过 Fish Audio MCP 生成，各环节使用的工具与记录符合职责。
- 录音稿与音频：正文、生成文本和说明分开，编号、版本、选用文件与分片顺序对应清楚；标签使用符合剧情，角色选声保持一致。关键变化的技术/转写/听音结果分别记录，问题段有修复记录，未试听内容不标为听音通过。
- 视觉与素材：画面与封面遵守选中的形式，兼顾构图、配色、光影与美感。像素形式检查逻辑网格，卡通形式检查线条和夸张表演的一致性；每个动作交付完整图片，同组画布、比例及锚点一致，换帧没有无意漂移或裁断，肢体、重心、遮挡与道具接触合理。
- 信息表达：形式适合内容且有巧思，数据与细节依据准确，展示时机合理，手机尺寸可读，不遮挡表演或字幕；使用动态数据时，其定义、状态与更新规则一致。
- 场景连续性：固定结构、角色与对象身份一致，动态状态符合相应剧情时刻；机位、遮挡和时间组织均有合理依据。
- 叙事与表演：行为符合人物意图和故事条件，动作与反应有因果，重复、停留、转折和省略服务于节奏；关键过程与结果清楚，复用不造成错误状态。尾声保留采用剧本的结尾意图，开放的问题有线索，本期应交代的结果与最后一幕完整呈现。
- 动作、声音与字幕：视觉变化、信息显示、音效和配音在同一时间轴上对应，定位与接触稳定；声音完整，字幕保持标准正文，控制标签不进入字幕，采用当前版本。
- 封面与成片：封面按 [封面与发布](covers-and-publishing.md) 检查创意、美感、小尺寸识别和内容契合度；成片规格按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 验证，章节与结尾完整，工程可依据已保存的素材和配置重新合成。

## 阶段与最终交付

阶段成果包括完整录音稿与生成清单、图片素材、核验通过的配音，以及动画样片。本次目标为完整动画时，交付阶段成果后继续推进，最终交付以下文件与记录；用户明确限定阶段或局部修改时，交付相关实际成果并保存续作记录：

- 唯一正式完整成片：像素形式沿用 pixel_limited_animation_1080p.mp4，卡通形式使用 satirical_cartoon_1080p.mp4，规格按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 执行；按选中的形式交付其中一个。
- 与成片同名的 SRT 字幕：pixel_limited_animation_1080p.srt 或 satirical_cartoon_1080p.srt，采用当前正式成片的文本与定时。
- cover_4x3.jpg、cover_3x4.jpg、cover_16x9.jpg，以及 PNG 无字底图或可编辑文件；附三种构图小样、方案选择理由及缩略图检查记录。
- douyin_publish_copy.txt：包含 [封面与发布](covers-and-publishing.md) 规定的发布标题、两种长度的介绍、话题及适用的系列信息。
- 最终采用的录音稿.md，包含朗读正文、生成文本及标签意图；附 Fish Audio MCP 原始音频、章节与段落音频及必要工程副本，保留版本、来源和对应关系。
- project_state.json：指向采用剧本、各阶段成果与版本、检查结果、实际工具缺口及继续制作所需信息，按 [阶段衔接与续作](handoff-and-resume.md) 保存。
- 当前采用的完整剧本，保留适用的来源、事实说明与类比边界；用户已有剧本沿用来源，适配或修订保留版本。
- audio_manifest.json、成片时间轴、音频与字幕定时、技术/转写/听音检查及修复记录；选用关系、版本和时间映射按 [配音与音频](voice-and-audio.md) 保存，与导出成片对应。
- voice_casting.json、fish_audio_mcp_settings.json、fish_audio_mcp_jobs.json 及 MCP 调用记录，内容按 [配音与音频](voice-and-audio.md) 保存，与最终使用的音频对应。
- 环境声、动作音效、音乐的独立素材与完整混音。
- 镜头与动作时间表、按需整理的场景与表演状态记录、信息表达记录，保留剧情与成片时刻、素材及版本对应。附实际使用的背景、前景、包含嘴形/表情/手势的完整角色姿势或完整镜头动作图片、特效和视觉辅助素材；像素形式保留逻辑分辨率源文件，卡通形式保留未损坏线条的原始与工程图片。
- 实际用于检查的分镜预览与样片，标明“过程检查素材”，与正式成片分开整理。
- 可复用的分层合成工程或脚本，包含素材路径、图层关系、统一定位、姿势时长、循环、镜头、音轨、字幕及所选形式的采样和输出配置；附 Image Gen 的实际生成与编辑提示词、参考素材及可核实配置。
- 美术规范与素材清单：包含 `visual_style`、采用的美术基准、画布/采样/倍率、调色板、姿势组与完整基准、统一素材尺寸/角色比例/锚点、帧序及整组对齐检查结果，以及视觉素材的工具和来源。像素形式另保存逻辑网格规范，卡通形式保存线条、表情强度与特写设定，便于核对、续作与复用。
- 场景设定表、基准背景及实际使用的机位和状态版本，包含固定结构清单、状态变化及剧情依据；附跨镜头、跨时间的场景连续性检查记录。
- 素材、动作、声音、封面和成片检查记录，区分技术校验、画面检查、听音及连续播放，标明实际覆盖范围和待核验项。
- 制作说明：实际时长、导出规格、素材复用方法、关键设计、检查结果与仍存在的限制；附各阶段实际工具的名称、可核实的版本、用途及合成和导出配置，与 [主入口的工具分工](../SKILL.md#全流程约束) 一致。

交付说明以实际成果和检查结果为依据。工具或素材缺失影响进度时，列明问题、已完成内容及恢复所需条件，继续推进可执行工作；未制作、未播放或未验证的内容不得标为完成，调用记录仅包含实际执行的操作。
