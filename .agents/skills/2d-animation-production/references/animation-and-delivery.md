# 动画与交付

建立成片时间轴、制作样片、上/下或上/中/下动画、字幕、导出及最终检查时读取。只写剧本的交付见 [剧本创作](scriptwriting.md)；本文件的分段成片清单适用于动画制作目标，局部修改或单段制作按本次范围交付有关成果。

正式动画与采用剧本的分段一一对应，上/下交付两段视频，上/中/下交付三段视频，每段目标约 3–5 分钟。本文件中的“全片”或“整片”指本期全部叙事段的整体完成与连续性，不要求将它们合成一个长视频；合并长片不能替代分段成果。每段包含本段全部剧情、配音与结尾，整套交付覆盖全部已要求的段。

用户指定的已有剧本已采用上/下或上/中/下时直接沿用；尚未分段时，保持核心剧情、对白含义与结局，先在制作方案中按自然转折确定两段或三段的边界与时长，再按确认后的分段制作。内容不足以支撑目标时长或分段需要实质改写时，提出具体取舍，不靠机械截断或灌水适配。

采用版本及阶段恢复见 [阶段衔接与续作](handoff-and-resume.md)。角色素材与表演见 [视觉与表演](visuals-and-performance.md)，声音的选用和工程时间映射见 [配音与音频](voice-and-audio.md)，封面与文案见 [封面与发布](covers-and-publishing.md)。

执行用户选择的 [动画路线](animation-routes.md)：连续动画用关键图生成视频，翻页动画用至少六图逐帧切换。两路均用可复用本地工程统一采用画面、声音、剪辑、字幕及分段导出；不要求把生成视频重画为独立姿势。运行依赖和配置见 [制作执行](production-execution.md#合成工程与共同时间轴)，已有软件工程须确实可控制才能接续。

## 1080p 输出与字幕

1. 按采用剧本的上/下或上/中/下分别输出正式 MP4，每段目标约 3–5 分钟，均为横屏 16:9、1920×1080、24 fps、H.264 视频与 AAC 音频；每段仅选用一个当前正式版本，历史文件保留必要追溯。采用的段名、顺序和边界来自剧本，不按分钟数机械切割长片。
2. 使用合成软件或本地脚本，按作品选中的形式完成画面。简笔水彩按 [水彩形式](style-simple-watercolor.md) 在 1920×1080 组织画面，使用保留线稿、柔和晕染和透明边缘的统一采样；讽刺手绘卡通按 [卡通形式](style-satirical-cartoon.md) 使用最终尺寸及适合线条的采样。再添加最终分辨率的文字层，导入定稿配音，完成字幕渲染、音画合成与编码；保存视觉形式、画布、采样、实际倍率、工具及导出配置。分镜预览和样片归入过程素材。
3. 字幕准确同步，每屏尽量不超过两行，固定在画面安全区域，不遮挡表情、关键动作和重要道具。
4. 每段分别生成与本段 MP4 同名的 SRT，时间从该视频的零点计算。字幕文字取自本段朗读正文，依据实际配音及可确认的语义短段起止定时，核对全部对白、旁白和正文中的拟声词；支持听音时进一步复查，不根据文本均分伪造逐字定时。标签、导演说明及用于纠正读音的替代拼写不进入字幕；纯笑声、叹气等不直接显示为控制标签。自动识别结果仅辅助校验，本段 MP4 与 SRT 共用最终文本和定时，不能沿用上一段或整体剧情的字幕时间偏移。
5. 工程保留叙事呈现顺序及故事时刻与各段实际时间的对应关系，每段的画面、最终混音与字幕共用从零开始的本段时间轴，包括本段配音、留白、无声动作及必要片头片尾。段尾悬念、下一段承接及最后一段收束与剧本一致，配音完整且不被拉伸或截断。逐段读取规格、完整解码并核对长度与本段内容覆盖；查看各镜头及关键变化，环境支持时完整播放本段，再按段序检查前后衔接。检查字幕不越出本段时长，台词未被无意截断，跨段动作有已确认的停点、帧序及恢复位置，按实际方式记录，不把成功编码或抽帧称为完整观看。

## 制作流程与质量检查

按“主剧本确认 → 分段确认 → 路线与清单确认 → 共用标准参考 → 当前片段关键图/画布确认 → 当前动态画面与声音 → 自查修复 → 用户确认该片段 → 下一片段”顺序制作。两路共用 [逐片确认](animation-routes.md#逐片生成与用户确认)，本片段内部可并行，后续专属图片/音视频不提前投产。首片兼作样片，不能凭样片通过批量生成。

连续性贯穿上述阶段：先按 [事件链](story-continuity.md) 核对决定、执行、合理省略、结果/交接、回应与下一步，再落实镜头覆盖及边界状态，最后制作组内过渡帧。清单与画布审阅同时展示关键事件顺序、省略和承接，不增加一套独立确认流程；已有确认的内容沿用，实质创作变更再更新相应范围。

各段使用已确认剧本中的 [旁白](scriptwriting.md#旁白参与故事说明与剧情推动) 说明背景、衔接时空和推进处境，录音及声画编排按 [旁白身份与声音编排](voice-and-audio.md#旁白身份与声音编排)。将每处正文、用途、关联事件/镜头及真实音频起止落实到本段时间轴，旁白和动作可同步进行，时长按实际共同时间轴核定；关键对白与反应留出空间。样片包含有代表性的旁白与画面承接，供用户判断叙述是否自然、信息是否清楚及是否推动后续。

[多时间线](dramatic-suspense-and-timelines.md) 在制作中保留真实事件先后、呈现顺序和各段播放时间的映射；按对应历史状态选择素材和声场，回到原线接续其状态。每处切换先判断连续动作、合理省略、跨线或回归，核对其定位与信息；主线线索的铺垫、核验、回收以实际画面/声音为准，正文有说明而成片看不到或听不到仍属缺口。样片可附跨线分镜或边界预览验证理解，不扩大成未经授权的额外成片。

1. 核对主剧本与分段确认，按场景交互提取清单，向用户提供“连续动画 / 翻页动画”选项；明确选用即记路线。自查并确认清单，不默认固定双人对白。
2. 检查生图/视频及工程能力、额度和报价，建立共用人物/场景/道具参考；按 [片段规则](animation-routes.md#逐片生成与用户确认) 将镜头计划拆成有稳定编号的短视频或动作单元，保留事件、历史状态、顺序与时长依据。
3. 仅生成当前片段关键图入画布，补齐该范围剧情、线索、接触/结果及承接，自查后取得对应画布确认。未来片段按文字计划待制作，不要求提前补齐实图。
4. 按 [Fish 配音](voice-and-audio.md) 完成当前片段所需对白、旁白与人物发声，复用已选音色和合格旧声音，登记实际音频选用、时长与检查。未试听不标通过，完整录音稿可预先整理但后续专属配音不提前生成。
5. 连续动画只生成当前图片对的视频，负责画面及所需音效/环境声，检查实际运动与首尾；翻页动画按上一合格帧补至当前每个变化至少六张完整图片，检查全组后本地换帧。发声表演依本片段真实 Fish 配音定时，不把三图、六图计数或编码成功当作动作通过。
6. 统一当前时间轴、画面、非人声音效、Fish 配音及字幕，分别记录来源和采用版本；音乐独立组织。去除视频误生人声但保留或补齐所需音效，核对口型、接触、状态、混音和与已确认前片的连接。连续动画记录入出点与实际首尾，翻页动画记录帧序、锚点及姿势时长。
7. 输出当前可播放片段并自查修复，提供实际文件和具体确认项。首片兼作表现样片，时长由动作和声音决定，不提前生成后片来凑十至十五秒。请用户判断画风、对白/旁白、音效、互动、连续性与节奏；未确认只修当前片段。
8. 保存 `user_review.clips[clip_id]` 的版本、范围、决定与前片依赖，明确确认后才回到第 3 步制作下一片段。修改已确认内容时传播复查并更新相关确认；整集授权、首片确认或自查通过不能代替后续确认。已确认片段可拼接复查长段节奏与衔接。
9. 全部所需片段确认后，按剧本分别导出上/下或上/中/下 MP4 与同名 SRT，完成本段三比例封面和文案。核对规格、解码、全部剧情/声音覆盖、字幕零点、镜头与段界，支持时完整播放听音；修复后复查受影响版本与确认范围。
10. 按 [完整交付](#阶段与最终交付) 整理采用剧本、原始及工程素材、Fish 音频、生成音效、调用/报价和逐片确认记录、可复用工程及检查依据。不能以关键图、首片或计划代替整套分段动画。

每次提交样片、选用叙事段或交付全片前执行“取得实际文件与检查视图/声音→检查→修复→复查”，记录对象、版本、问题位置、方法、覆盖范围、修复及结果。检查覆盖全部采用图片、动作段、叙事段和当前最终文件；单张图片合格、样片通过或成功编码均不能代表整片自查通过。具体证据要求见 [制作执行与能力边界](production-execution.md#检查依据与适用边界)，检查重点为：

- 流程与工具：主剧本、分段、用户路线选择、清单、当前范围关键帧画布及每片确认均有版本/范围与依据；图片即梦优先/备用、节点/本地对应、画布缺口/补齐及同步状态明确。连续动画另保存真实视频、音效与报价/授权，人物配音由 Fish 提供，不用 Image Gen 或 Fish 生视频；不在确认前投产依赖工作。
- 录音稿与音频：正文、生成文本和说明分开，编号、版本、选用文件与分片顺序对应清楚；标签使用符合剧情，角色选声保持一致。关键变化的技术/转写/听音结果分别记录，问题段有修复记录，未试听内容不标为听音通过。
- 旁白与剧情：上/中/下各段都有实际说明或推进作用的旁白，正文、音频、镜头及字幕一一对应，叙述视角和音色稳定；核对时空衔接、因果与人物信息范围，画面仍有实际活动和关键交接/结果。旁白不重复解释显然可见的动作，不抢关键对白与反应，不触发无关人物口型；缺失、重复、提前泄露、误报完成或与画面状态矛盾的部分修复后复查。
- 视觉与素材：采用同一画风，水彩检查线稿、淡彩、纸纹和柔边稳定，卡通检查线条与表情一致。连续动画检查全部关键图、采用视频运动及每处连接；翻页动画检查全部完整图片、六图计数、同组画布/比例/锚点及全部切换。按 [肢体检查](visuals-and-performance.md#肢体与头身动作检查) 核对手脚归属、连接、头身转向和支撑，异常修复后复查完整动作，不凭静态首尾放行生成视频。
- 信息表达：形式适合内容且有巧思，数据与细节依据准确，展示时机合理，手机尺寸可读，不遮挡表演或字幕；使用动态数据时，其定义、状态与更新规则一致。
- 场景连续性：固定结构、角色与对象身份一致，动态状态符合相应剧情时刻；机位、遮挡和时间组织均有合理依据。按 [视线与道具朝向](visuals-and-performance.md#视线阅读面与道具朝向) 核对手机、书、纸条和票据等阅读动作，正面机位显示道具背面，可读面朝人物；换帧、转动、翻页与切镜头后保持关系成立。
- 事件与镜头连续性：按 [三层检查](story-continuity.md#自查与修复顺序) 核对全部关键事件和所有事件/镜头/场景/分段边界。决定有执行，省略两端可推断，交接结果与任务进度一致，人物先获得信息再回应，下一步由前事支持；对照实际采用的前镜末态与后镜初态，缺事件、缺连接、缺姿势和剪辑错序分别修复。单图合格、组内流畅和帧数达标都不能替代这一检查。
- 多时间线与悬疑：先按故事时间核对真实因果，再按播放顺序核对当前揭示范围，检查跨线定位、历史状态、人物/观众知识、同一事件回放和段尾待决结果的恢复。逐条核验线索在实际画面/声音中可感知并已回收，各线的提问与解释形成实际推进，最后一段完成因果、旧细节和人物情感的汇合。连贯观看后应能复原关键先后、理解人物动机和证据关系；旁白、对白、动作和场景没有互相泄底或矛盾，有意隐藏按计划兑现，不能以悬疑为由保留主线缺口。
- 叙事与表演：行为符合人物意图和故事条件，动作与反应有因果，重复、停留、转折和省略服务于节奏；关键过程与结果清楚，复用不造成错误状态。按 [动作与场景交互](visuals-and-performance.md#动作与场景交互) 连贯检查整场与整段，人物有实际活动、互动与空间调度，镜头能呈现接触和结果；连续退化为固定背景前双人轮流说话、仅靠嘴形或无目的动效推进时，回到动作与镜头设计修复。尾声保留采用剧本的结尾意图，开放的问题有线索，本期应交代的结果与最后一幕完整呈现。
- 动作、声音与字幕：视觉变化、信息显示、音效和配音在同一时间轴上对应，定位与接触稳定；声音完整，字幕保持标准正文，控制标签不进入字幕，采用当前版本。
- 封面与成片：封面按 [封面与发布](covers-and-publishing.md) 检查创意、美感、小尺寸识别和内容契合度；成片规格按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 验证，叙事段与结尾完整，工程可依据已保存的素材和配置重新合成。
- 话题生成剧本的分段：用真实配音与动作核对上/下或上/中/下各段约 3–5 分钟的目标，本段看点/回报、段尾悬念及后段兑现仍与采用剧本一致；偏离目标时调整实际内容与节奏并按变更规则复查，不通过拉伸配音、重复静帧或空白画面凑时长。

## 阶段与最终交付

阶段成果包括完整录音稿与生成清单、图片素材、核验通过的配音，以及动画样片。本次目标为完整动画时，按确认节点交付可审阅成果、处理反馈后继续推进，最终交付以下文件与记录；用户明确限定阶段或局部修改时，交付相关实际成果并保存续作记录：

- 上/下交付两组分段成片，上/中/下交付三组，按段序组织到 `deliverables/P01_上/`、`deliverables/P02_下/`，或 `deliverables/P01_上/`、`deliverables/P02_中/`、`deliverables/P03_下/`。每组包含本段唯一当前正式 MP4，例如 `P01_上_1080p.mp4`，其他段按实际标识/段名命名，规格按 [1080p 输出与字幕](animation-and-delivery.md#1080p-输出与字幕) 执行；视觉形式保存在工程与素材记录中，各段保持一致。
- 每组对应同名 SRT，例如 `P01_上_1080p.srt`，采用本段最终文本及从本段零点开始的定时。
- 每组各有 `cover_4x3.jpg`、`cover_3x4.jpg`、`cover_16x9.jpg`，以及对应 PNG 无字底图或可编辑文件；围绕本段真实看点设计，附构图小样、方案选择理由及缩略图检查记录。
- 每组各有 `douyin_publish_copy.txt`，包含本段推荐标题、备选标题、两种长度的介绍、话题及系列名/上中下标记，内容按 [封面与发布](covers-and-publishing.md) 保存，保护后段反转与结局。
- 最终采用的录音稿.md，包含朗读正文、生成文本及标签意图；附 Fish Audio MCP 原始音频、叙事段与段落音频及必要工程副本，保留版本、来源和对应关系。
- project_state.json：指向采用剧本、各阶段成果与版本、检查结果、实际工具缺口及继续制作所需信息，按 [阶段衔接与续作](handoff-and-resume.md) 保存。
- 当前采用的完整剧本，保留适用的来源、事实说明与类比边界；用户已有剧本沿用来源，适配或修订保留版本。
- audio_manifest.json、各段成片时间轴、音频与字幕定时、叙事呈现顺序及故事时刻/跨段状态映射、技术/转写/听音检查及修复记录；选用关系、版本和时间映射按 [配音与音频](voice-and-audio.md) 保存，关联具体段标识和导出版本。
- voice_casting.json、fish_audio_mcp_settings.json、fish_audio_mcp_jobs.json 及 MCP 调用记录，内容按 [配音与音频](voice-and-audio.md) 保存，与最终使用的音频对应。
- 环境声、动作音效、音乐的实际采用素材与完整混音；生成视频中采用的音效保留来源与可用分轨，配音明确来自 Fish。
