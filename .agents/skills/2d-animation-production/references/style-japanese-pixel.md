# 日系唯美像素形式

仅在 `visual_style` 为 `japanese-pixel` 时读取。以清晰的像素结构、协调的日系配色、精细生活场景和有意图的有限动画形成独立美术规范。完整动作图片及连续性见 [视觉与表演](visuals-and-performance.md)，运行工具、程序合成及检查方式见 [制作执行与能力边界](production-execution.md)。

## 制作方式与能力边界

Agent 组织美术设定、场景和表演，调用 Image Gen 创作及编辑完整图片，再通过本地图片处理与合成工程统一规格、控制换帧和导出。美术内容、像素结构和角色身份由实际查看结果确认，程序处理保证明确的画布、定位及时间轴规则。

Image Gen 的提示约束不能保证一次得到精确网格、完全相同的人物或相同锚点。先以完整场景和角色动作小组验证画风、同组一致性及合成链路，再扩展素材；保持要求未满足时修改或重生成问题图片。逻辑尺寸、独立姿势数量、动作替换速度与输出帧率是工程设置，分别保存。

## 构图与情境表演

1. 先设计可理解的完整故事场景，明确空间、光源、角色活动区域及前后遮挡。建立环境的镜头可以呈现全身人物和足够背景，让观众知道人物在哪里、面对谁、与什么对象发生关系；景别随叙事需要选择，不把所有镜头固定为全身正面排列。
2. 用有辨识度的像素轮廓、脸型、发型、服装和主色表达人物，动作轮廓简洁清楚。背景可以有更丰富的建筑、家具与生活细节，人物保持较克制的细节；两者共用像素网格、调色板关系、光照和空间，不要求每块区域拥有相同细节数量。
3. 站位与视线围绕对话对象、人物关系和动作目的安排。说话者可用完整姿势图中的嘴形、表情与手势变化，听者有适当反应；通过停留、转身、接近、退开或关键姿势推进剧情，不只给静态角色持续添加相同弹跳。
4. 情节涉及移动、操作或接触时，选择能看懂起因、过程与结果的完整姿势；人物与随动作表现的道具一起生成，保持重心、接触与遮挡。背景复用，同组完整图片按统一画布及锚点换帧；不生成嘴、手或肢体碎片后拼接。
5. 同一地点的昼夜或情绪气氛可以借助调色板、分级明暗及独立环境效果变化，但固定结构与人物身份继续依据基准。暖灯、冷月色、火光或烟雾用像素色块和必要效果帧表达，背景整体稳定，变化不能令无关物体漂移或消失。
6. 镜头切换服务于人物行动、信息揭示和情绪节拍。需要时使用相应景别的完整素材与整像素平移，保留理解、反应和阅读时间；关键因果在完整镜头中可理解，人物通过姿势、反应与位移演出，而非只给静态画面不断推拉。

## 像素美术与角色一致性

1. 整体采用偏日系唯美的精细二维像素美术，保留清楚的像素色块、阶梯轮廓和有取舍的细节。用协调的调色板、成组色块与分级明暗表现体积、光照和空间；构图讲究疏密、留白和前后层次，轮廓干净，细节精致。
2. 日系唯美感通过清透协调的色彩、含蓄的情绪、细致的生活场景与有气氛的光影体现。按剧情安排日光、月色、灯光和冷暖对比，既保持美感，也让冲突与情绪清楚；用像素色块表现光影层次，避免平滑渐变、照片纹理与过度锐化。
3. 人物适度 Q 版，头部略大、身体简洁，头身与体型根据年龄、身份和角色设定安排，避免所有人都变成相同的大头比例。五官、发型、服装、配饰及姿态清楚可辨，表情主要通过眼睛、眉形、嘴形及身体姿势表达，像素数量有限时仍要体现角色差异。
4. 场景完整且具有前后层次，包括必要的建筑、家具、植物与道具。背景和角色保持相同的像素网格及协调的细节取舍；可以背景较丰富、人物较简洁，不能将平滑绘画或照片背景与粗像素角色混用。
5. 工程默认使用 640×360 逻辑画布，最终以最近邻方式放大三倍到 1920×1080。Image Gen 实际返回尺寸与工程逻辑尺寸分别记录，不能只在提示中写尺寸便认定可直接合成。先检查小样的轮廓、色块、边缘和手机可读性，按统一规则建立工程图片；其他逻辑尺寸须能整数倍放大到目标分辨率。动画样片若触发美术规范变化，则更新受影响素材和配置。
6. 完整角色姿势、道具、背景及特效都遵守同一逻辑像素网格，嘴形和表情包含在完整姿势中。位置、锚点、裁切和遮挡边界按整像素对齐，不能因小数坐标、平滑缩放或模糊滤镜造成边缘闪烁。
7. 建立统一风格与角色参考，固定人物比例、脸型、发型、服装、主色、像素轮廓粗细和明暗层级。跨镜头、跨姿势持续复用相应参考。
8. 先建立已确认的标准人物图和当前镜头完整初始帧，连续姿势按 [上一帧微调](visuals-and-performance.md#标准参考图与上一帧微调) 以前一合格帧为编辑目标，保留同组画布、定位及固定属性，编辑后仍交付完整姿势图片。对照标准图检查逻辑尺寸下的像素结构、放大后的边缘、身份一致性及整组换帧对齐；不能仅靠重复角色名字保证身份一致。
9. 像素美术从逻辑画布与素材结构开始制作，不使用给写实图片覆盖马赛克或仅降低视频清晰度的方法模拟。
10. 根据剧本的时代、地点和人物身份设计服装、建筑及道具，保留足以区分人物和解释剧情的特征，不堆砌低分辨率下无法辨认的细节。
11. 从 16:9 逻辑画布规划构图，在最终输出尺寸和手机尺寸检查表情、动作、道具及信息视窗；主体关系清楚，重要细节可辨，避免拉伸、关键内容裁切或画面拥挤。
12. 像素网格规范适用于故事画面、细节放大素材和封面主视觉。标题、字幕、计数器数字及说明文字在逻辑画布预留位置，必要时在最终分辨率独立排版，以清楚、美观、易读为准，不强制使用像素字体。重要文字和数值使用经过核对的文本层，封面画布按 [封面与发布](covers-and-publishing.md) 适配。

## 实现与校验

先用 Image Gen 制作一个完整场景构图和角色小样，核对人物关系、空间层次、像素结构、调色板及手机尺寸可读性，再建立固定机位背景与完整角色基准。角色姿势图保留完整轮廓、手持道具、动作余量和透明画布，人物通过一致光照、接触阴影与遮挡进入场景。

每组动作以标准人物图和镜头初始帧固定身份与场景，再以上一合格帧逐步微调姿势、表情和嘴形；每次只改变指定区域，检查通过后继续下一帧。每张结果都是可直接替换的完整图片，按 [完整动作帧与对齐校验](visuals-and-performance.md#完整动作帧与对齐校验) 核对画布、比例、锚点和非动作区域。火焰、烟雾等独立环境效果按其统一画布组织，不重生成无关背景。

使用合成软件或本地脚本复用背景，按成片时间轴控制整图换帧、角色整体位移、前后遮挡、必要环境效果及镜头剪辑。依据已确认的选用配音和时序安排嘴形、停顿、听者反应、字幕及声音触发，未完成的听音检查继续记录；24 fps 输出帧率与动作图片的替换速度分别记录。

在 [动画与交付](animation-and-delivery.md) 要求的代表性样片中，优先检查完整场景里人物是否自然、表演是否能看懂，以及换帧对齐、道具接触、跨镜头状态和阅读节奏。通过检查的逻辑画面按固定整数倍率最近邻放大，文字在最终分辨率独立排版，封面与正文沿用同一像素规范。

组织生图提示时直接说明用途、主体、情境、构图、像素画法、光源与需要保持的条件。日系唯美感用协调调色板、清楚的像素色块、分级明暗、前中后层次及细致生活环境表达，避免只写抽象的“美观”。动作编辑明确完整基准及本次变化，输出完整角色和关联道具，保留同组画布、比例和锚点。图片不承担字幕或计数数值的最终排版，这些内容由代码或排版工具使用核对文本实现。
