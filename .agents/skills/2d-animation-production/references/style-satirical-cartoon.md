# 讽刺手绘卡通形式

仅在 `visual_style` 为 `satirical-cartoon` 时读取。共用的完整动作图片、场景连续性和有限动画要求见 [视觉与表演](visuals-and-performance.md)，结尾构思见 [剧本创作](scriptwriting.md#结尾设计与观众参与)。

## 制作方式与表现重点

通过简洁二维线条、克制色块、强表情、对比构图与有依据的荒诞意象表达人物关系和讽刺。每个作品独立设计角色、场景、行为及结尾，表演强度由本期主题和情境决定。

主剧本、分段稿、清单及用户 [路线选择](animation-routes.md) 确定后，按 [生图路由](canvas-and-image-routing.md) 建立标准参考与关键图、入画布并补齐缺口。画布确认后，连续动画生成相邻状态视频，翻页动画按 [上一帧微调](visuals-and-performance.md#标准参考图与上一帧微调) 补至每个变化至少六张有效完整图；均按 [逐片确认](animation-routes.md#逐片生成与用户确认) 只做当前片段，自查并经用户确认后再生成下一片。连续动画核对实际片内/连接，翻页动画核对全部图/切换，本地工程统一剪辑或换帧、声音、文字与输出。工具及检查依据见 [制作执行](production-execution.md)。

## 美术与构图

1. 采用二维手绘卡通语言，轮廓清楚、线条统一、平涂色块和适度分级阴影。人物与场景的细节有取舍，构图、美感及辨识度持续保持，不用随意涂画或低清晰度代替风格。
2. 日常场景可用简洁角色和克制表演，冲突或心理转折可用更强的表情、近景、明暗和构图对比。通过脸型、发型及识别特征保持角色身份，同组固定服装与比例；跨故事时刻使用已确认的年龄/服装/场景版本，特写强度变化不能让人物变成另一个角色。
3. 画面信息围绕动作与人物关系组织。对白气泡、并置画面、数字或象征性道具按叙事需要选用，使用核对后的文字层，手机尺寸可读；气泡与字幕组织阅读顺序，避免两套相同长句同时挤占画面。
4. 荒诞、夸张或象征性变化应有主题和剧情依据，观众能理解其对应关系。强烈视觉只用于确实需要的转折，不把冲击性细节作为讽刺成立的前提。
5. 默认在 1920×1080 制作画面和布局，也可使用有足够清晰度的更高分辨率源图；按整组统一规则整理动作图片。保留干净的平滑线条和透明边缘，缩放采样以线条清晰和运动稳定为准。

## 有限动画与剪辑

以下整图换帧、姿势计数和循环实现用于翻页动画。连续动画按 [连续动画](animation-routes.md#连续动画) 制作，不另要求六图；两路共用表演、风格、镜头和连续性标准。

1. 以完整姿势图片或完整镜头动作图片直接换帧，结合整张素材位移、停留和镜头剪辑。全部嘴形、表情、手势及身体变化包含在完整动作图片中，背景与独立对象按实际需要分层，不生成身体片段拼接。
2. 重复动作制作一组对齐的完整关键姿势，按实际速度和表演意图循环；轮子、肢体、身体及所持对象的运动关系在完整图中正确呈现。对话或反应变化时切换对应完整姿势，不仅让静态整图持续弹跳。
3. 有目的的整图平移、镜头推拉与轻微震动可以连续变化，姿势内容仍通过完整图替换。保存构图、中心或支点及统一尺度，避免不同帧各自居中或缩放造成漂移。人物形变使用有依据的新动作图片，不靠任意拉伸整图模拟肢体运动。
4. 冲突升级可通过反应特写、对比构图、节奏停顿、色调变化和必要的效果帧增强；动作、结果与情绪转折仍须有因果。普通对白不需要逐句变换景别，也不要求每个镜头都加推拉和抖动。
5. 24 fps 是正式成片的输出帧率，独立动作图片的数量和替换速度另行安排，起点见 [动作与表演](visuals-and-performance.md#动作与表演)。以选用配音和代表性样片校准节奏、表情和同步，记录实际检查及待核验项。

## 封面与输出

封面沿用所选角色、线条、色彩和卡通表现，完整图片中的情绪或关系形成清楚的点击动机。三种比例分别按最终尺寸构图，文字独立排版；创意、美感及缩略图检查按 [封面与发布](covers-and-publishing.md)。正式成片使用统一的 1080p 输出规格。
