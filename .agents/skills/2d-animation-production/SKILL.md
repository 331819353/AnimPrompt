# 二维动画创作与制作

创作有生活质感、戏剧性和悬疑吸引力的故事，制作完整的二维故事动画。按用户最新要求确定本次范围，复用已确认内容与合格成果。

## 选择本次范围

| 用户目标 | 执行模式 | 交付范围 |
| --- | --- | --- |
| 根据主题写故事或剧本，未要求成片 | 只写剧本 | 完整剧本、必要来源与制作交接 |
| 将已有剧本制作成动画 | 已有剧本制作动画 | 成片、字幕、封面、发布文案及工程 |
| 根据主题创作并制作视频 | 从主题到成片 | 剧本与动画全流程 |
| 续作、改编或局部修复 | 按指定范围处理 | 指定成果及受影响部分的复查 |

仅制作已有剧本时沿用采用内容；要求改编时可重组叙述并丰富剧情，保留事实与用户指定核心，提交具体改稿供确认。

## 选择视觉形式与结尾

| 形式 | 视觉标识 | 规范 |
| --- | --- | --- |
| 简笔水彩画 | `simple-watercolor` | [水彩形式](references/style-simple-watercolor.md) |
| 讽刺手绘卡通 | `satirical-cartoon` | [卡通形式](references/style-satirical-cartoon.md) |

新作品默认简笔水彩画；用户指定或续作已有选择优先。记录 `visual_style`，角色、场景、道具、特效与封面采用同一绘画语言；切换形式按变更规则更新相关素材。

结尾可完整收束、开放选择或循环反讽，按 [结尾设计](references/scriptwriting.md#结尾设计与观众参与) 处理。核心因果与结果讲清，开放的是有依据的未来选择。

## 推进流程

只写剧本：明确方向与必要事实 → 完整主剧本自查、确认 → 上/下或上/中/下分段剧本自查、确认 → 保存采用版本与交接。主剧本包含完整故事、场景、对白、旁白和结局，分段稿落实各段约 3–5 分钟的剧情、看点与承接。

动画制作使用“连续动画”和“翻页动画”作为用户选项与触发词。明确选用时分别记录为 `keyframe-video`、`frame-sequence`，内部标识保持兼容；只比较两种方式不算选择。最迟与清单一起确定 [路线](references/animation-routes.md)，未选择不投产视觉素材，工具不可用时不自动换路；只写剧本无需选择。

共同流程：主剧本确认 → 分段确认 → 路线及人物/场景/道具清单确认 → 共用标准参考 → 当前片段关键图入画布、自查补齐并确认 → 本片段 Fish 配音及连续视频/翻页帧序列 → 音效、混音、字幕与自查修复 → 用户确认实际片段 → 再生成下一片段 → 按剧本分段导出及交付。

两路均按 [逐片确认](references/animation-routes.md#逐片生成与用户确认) 顺序推进。片段指短视频或完整动作单元，区别于上/中/下整集；连续动画的每个相邻图视频分别确认，翻页动画按短动作单元合成预览。当前片段自查并获用户确认后才生成下一片段；本片段独立任务可并行，后续专属图片、音视频不提前生成。首片兼作样片，不以样片通过放行批量生成。

## 用户沟通与确认

主剧本、分段稿、清单、当前范围关键帧画布及每个实际动画片段分别确认，路线可与清单同次选择。记录成果版本、范围、用户决定及片段前后依赖；已有明确覆盖的确认可复用，待确认不提前投产下一片段。

主线、动机、事实解释或结尾存在疑问时，先核验可查部分，再说明问题、影响和建议；技术修复自主处理。未回复不等于确认，旧的笼统全权制作/跳过审稿不取消逐片确认；用户之后明确调整具体范围时记录新规则。详见 [用户沟通与确认](references/handoff-and-resume.md#用户沟通与确认)。

## 阶段自查

采用、提交审阅或交接前，执行“读取实际成果 → 检查 → 修复 → 复查 → 记录”。覆盖本次完整文本、全部采用图片及相关动作/叙事段，记录对象、版本、位置、方法和覆盖。可修复问题先解决；生成、技术核验、视觉、听音和连续播放分别记录，缺少检查条件的项目标为待核验。各阶段要求见 [阶段自查与放行](references/handoff-and-resume.md#阶段自查与放行)，证据边界见 [制作执行](references/production-execution.md#检查依据与适用边界)。

## 全流程约束

- 剧本分上/下或上/中/下，每段约 3–5 分钟，包含具体冲突、行动、自然对白、旁白、场景和本段回报。上/中段悬念有铺垫，后段兑现；保留事实与类比边界，不用静态对白、重复解释或空白凑时长。
- 创作/改编采用至少两条有作用的时间线，交叉提问、补足解释，最后汇合核心因果、线索与人物情感。分别记录故事时间、呈现顺序和成片时间；按 [多线悬疑](references/dramatic-suspense-and-timelines.md) 保持人物知识与历史状态正确。
- [对白](references/scriptwriting.md#对白保留自然说话的过程) 保留合理铺垫、补充、迟疑和长短句变化；[旁白](references/scriptwriting.md#旁白参与故事说明与剧情推动) 说明背景、衔接时空和推进处境，写入实际正文并对应画面。旁白、对白与动作各有作用，角色不因观众听到旁白就自动知情。
- 按 [叙事连续性](references/story-continuity.md) 核对决定、执行、合理省略、结果/交接、回应和下一步。人物实际与道具、空间和他人互动，关键接触及结果可理解，避免全片成为固定背景前两个人轮流说话。
- [阅读道具](references/visuals-and-performance.md#视线阅读面与道具朝向) 的可读面朝人物，正面机位看到背壳、封皮或纸背；内容展示另用合乎空间关系的镜头。[肢体检查](references/visuals-and-performance.md#肢体与头身动作检查) 覆盖数量、连接、支撑与头身转向，多手、多脚、粘连或异常扭转修复后复查动作段。
- 连续动画按镜头规划关键状态，默认三张，复杂接触增加关键图；相邻图生成视频后检查全部片内运动、实际首尾和片间姿势/速度衔接，不将三图或共同过渡图视为视频已合格。生成与剪辑时长分别记录，正面对白另核验口型。
- 翻页动画每个可见变化至少 6 张有效不同图片，复杂变化继续补帧；重复静帧或增加输出帧数不计数。画布确认后按 [上一帧微调](references/visuals-and-performance.md#标准参考图与上一帧微调) 生成，标准图锁定身份，尾帧约束终点，逐张及整组检查。六图下限不用于连续动画；两路均不拆嘴、头或肢体拼装。
- 图片按 [生图路由](references/canvas-and-image-routing.md) 检查即梦额度、报价和能力，优先即梦，不可用时按 `imagegen` 技能用 Image Gen；统一入作品画布并保存本地采用版本、来源和同步状态。未知任务先恢复原结果，不重复提交。
- Fish Audio MCP 仅用于音频，声音只从 [限定音色表](references/voice-and-audio.md#mcp-工具就绪与音色选择) 按性别和年龄段选择，旁白也适用；每次试听、正式生成及重生成明确传入所选 `voice_id`。图片整理、排版、合成、音频后期及编码使用相应工具。
- 视频生成只负责画面与非人声音效/环境声，全部人物配音由 Fish 负责；音效、配音、配乐分开采用和混音，去除误生人声时保留或补齐所需音效。连续动画不保证自动口型同步，按真实 Fish 声音核验；翻页动画独立配制音效，不强制调用视频模型。
- 朗读正文、表演说明、生成文本和选用音频分开管理，音频以 `audio_manifest.json` 为准。字幕取正文并依据真实声音定时，控制标签和说明不进入字幕；画外旁白不驱动画面人物嘴形。
- 按剧本分别交付两段或三段 MP4，每段 16:9、1920×1080、24 fps、H.264/AAC，配同名 SRT、三比例封面及发布文案；每段选用一个当前正式版本，共用可复用工程。规格及完整清单见 [动画与交付](references/animation-and-delivery.md)。

## 交付与恢复

交付实际文件链接，更新作品目录中的 `project_state.json`；状态、依赖、版本及恢复规则见 [阶段衔接与续作](references/handoff-and-resume.md)。只写剧本在文字范围停止；要求成片时完成全部指定段及配套成果，明确未完成与待核验项。
